1. Find Injection Point

حدد input ينعكس في الصفحة أو يُخزّن ثم يُعرض.

GET / Form parameter BROWSER / BURP
[PARAMETER]=[INPUT]
جرّب قيمة مميزة أولًا وابحث عنها في Response.
Stored input BROWSER
[FORM_FIELD]=[UNIQUE_TEXT]
إذا ظهرت القيمة لاحقًا لمستخدم/صفحة أخرى فهذا مسار Stored محتمل.

2. Manual Proof

استخدم Proof-of-Concept غير مؤذٍ داخل اللاب لتأكيد التنفيذ.

Basic harmless PoC BROWSER / BURP
<script>alert(1)</script>
إذا نُفذ JavaScript في السياق المقصود فهذا يؤكد XSS في ذلك السياق.
GENERAL REFERENCE — فشل هذا الـPoC لا يعني تلقائيًا عدم وجود XSS؛ الـpayload المناسب يعتمد على مكان انعكاس البيانات: HTML body / attribute / JavaScript string / URL وغيرها.
Reflection clue BURP SUITE
Search response for [UNIQUE_TEXT]
الـreflection وحده ليس XSS؛ راقب هل يتم encoding للرموز أو إدخالها في HTML/attribute/script context.

3. Burp Capture

اعترض الترافيك لتحديد parameter والطلب الفعلي.

التقاط الطلب BURP SUITE
Proxy → Intercept / HTTP history → Send to Repeater
أعد الاختبار من Repeater لتغيير قيمة واحدة ومقارنة الاستجابة.

4. XSSer

أوامر XSSer باستخدام placeholders.

GET request KALI TERMINAL
xsser --url '[URL]' -p '[PARAMETER]=XSS'
ضع XSS حيث يجب حقن payload.
Automatic payloads KALI TERMINAL
xsser --url '[URL]' -p '[PARAMETER]=XSS' --auto
استخدمه بعد فهم مكان الإدخال، وليس بدل التحقق اليدوي.
Forced PoC KALI TERMINAL
xsser --url '[URL]' -p '[PARAMETER]=XSS' --Fp "<script>alert(1)</script>"
PoC بسيط.
Authenticated request KALI TERMINAL
xsser --url '[URL_WITH_XSS]' --cookie='[COOKIE]' --Fp "<script>alert(1)</script>"
لا تحفظ Cookie حقيقي داخل الملف.

5. Verify Context

فرّق بين Reflected/Stored، واعتبر DOM XSS فقط إذا كان التنفيذ يحدث في المتصفح دون اعتماد واضح على HTML response من الخادم.

Reflected BURP / BROWSER
Request → Response → Browser render
القيمة تأتي من الطلب وتظهر في الرد الحالي.
GENERAL REFERENCE — النجاح = الـinput يرجع في الـresponse ويُنفذ داخل المتصفح في السياق الحالي.
Stored BROWSER
Submit → revisit affected page
القيمة تبقى وتُعرض لاحقًا.
GENERAL REFERENCE — النجاح = الـpayload يتم تخزينه ثم يُنفذ عند فتح الصفحة/السجل لاحقًا.
DOM clue BROWSER DEVTOOLS
Inspect DOM / client-side sinks
GENERAL REFERENCE: استخدمه فقط عندما يظهر أن JavaScript في الصفحة ينقل input إلى DOM.
GENERAL REFERENCE — راقب هل JavaScript في المتصفح ينقل input إلى DOM sink قابل للتنفيذ حتى لو لم يظهر payload في HTML response من السيرفر.
