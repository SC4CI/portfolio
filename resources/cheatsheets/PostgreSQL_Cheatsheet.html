1. Reconnaissance

ثبّت الهدف ومسار الشبكة قبل فحص PostgreSQL.

معرفة عنوانك ومسار الشبكة KALI TERMINAL
ip a ip route
اختبار الوصول للهدف KALI TERMINAL
ping -c 4 [TARGET]
إذا ICMP محجوب، استخدم -Pn في Nmap وكمل الفحص.
اكتشاف الأجهزة عند الحاجة KALI TERMINAL
nmap -sn [SUBNET]

2. Port Scanning

PostgreSQL يستخدم افتراضيًا 5432/TCP، لكن ممكن يتغير.

فحص البورت الافتراضي KALI TERMINAL
nmap -Pn -p5432 -sV [TARGET]
Default Scripts + Version KALI TERMINAL
nmap -Pn -p5432 -sC -sV [TARGET]
فحص TCP شامل KALI TERMINAL
nmap -Pn -p- --min-rate 1000 [TARGET]
استخدم معدل الفحص المناسب للـLab أو نطاق الاختبار المصرح.
إعادة فحص البورت المكتشف KALI TERMINAL
nmap -Pn -p[PORT] -sC -sV [TARGET]

3. Enumeration

حدد الإصدار، طريقة Authentication، وقواعد البيانات والحسابات التي يسمح لك الخادم برؤيتها.

Nmap PostgreSQL Info KALI TERMINAL
nmap -Pn -p[PORT] --script pgsql-brute [TARGET]
هذا الـNSE مخصص لاختبار تسجيل الدخول؛ استخدمه فقط إذا كانت محاولات كلمات المرور مصرح بها.
اختبار اتصال psql بحساب معروف KALI TERMINAL
psql -h [TARGET] -p [PORT] -U [USERNAME] -d [DATABASE]
سيطلب Password إذا كانت طريقة المصادقة تتطلبه. قاعدة postgres شائعة كقاعدة إدارية لكن لا تفترض وجودها دائمًا.
عرض إصدار PostgreSQL بعد الدخول PSQL SESSION
SELECT version();
معرفة المستخدم الحالي وقاعدة البيانات PSQL SESSION
SELECT current_user, current_database();
عرض قواعد البيانات PSQL SESSION
\l
عرض الـSchemas PSQL SESSION
\dn
عرض الجداول PSQL SESSION
\dt *.*
عرض الأدوار والحسابات PSQL SESSION
\du
راجع Superuser وCreate role وCreate DB وغيرها من الخصائص.
عرض معلومات الاتصال PSQL SESSION
\conninfo

4. Credential Testing

اختبر Credentials المصرح بها، ثم استخدم Password Testing فقط إذا كان ضمن نطاق اللاب.

اختبار Credential مباشرة KALI TERMINAL
PGPASSWORD='[PASSWORD]' psql -h [TARGET] -p [PORT] -U [USERNAME] -d [DATABASE] -c 'SELECT current_user;'
إذا نُفذ الاستعلام ورجع المستخدم الحالي فالمصادقة نجحت.
Hydra Password Testing KALI TERMINAL
hydra -L [USERLIST] -P [WORDLIST] -s [PORT] [TARGET] postgres
Password attacks قد تسبب Lockout أو ضوضاء حسب البيئة. نفذها فقط داخل Lab أو بتصريح صريح.
Metasploit PostgreSQL Login Scanner MSFCONSOLE
search postgres_login search type:auxiliary postgres
اختر Login Scanner الموجود فعليًا في إصدار Metasploit عندك.
ضبط Scanner بعد اختيار الـModule MSFCONSOLE
use [POSTGRES_LOGIN_MODULE] show options set RHOSTS [TARGET] set RPORT [PORT] set USER_FILE [USERLIST] set PASS_FILE [WORDLIST] run
راجع show options لأن أسماء الخيارات قد تختلف بين Modules/الإصدارات.

5. Database Access / Permission Assessment

بعد دخول ناجح، قيّم صلاحيات الحساب وإمكانية قراءة البيانات أو الوصول لميزات قوية مرتبطة بالخادم.

تحذير: تأكد من الإصدار والصلاحيات قبل أي Exploit. لا تستخدم CVE أو Module لمجرد أن 5432 مفتوح.
فحص هل الحساب Superuser PSQL SESSION
SELECT current_user, usesuper FROM pg_user WHERE usename = current_user;
Superuser يغيّر مستوى المخاطر بشكل كبير؛ لا تفترض الصلاحية قبل التحقق.
عرض صلاحيات Roles PSQL SESSION
SELECT rolname, rolsuper, rolcreaterole, rolcreatedb, rolcanlogin FROM pg_roles;
Enumeration للجداول المهمة PSQL SESSION
SELECT table_schema, table_name FROM information_schema.tables WHERE table_schema NOT IN ('pg_catalog','information_schema');
قراءة بيانات من جدول مصرح PSQL SESSION
SELECT * FROM [SCHEMA].[TABLE] LIMIT 20;
حدد الجدول بعد Enumeration ولا تخمّن بيانات أو نتائج.
البحث عن PostgreSQL Modules MSFCONSOLE
search postgres search [POSTGRES_VERSION]
طابق أي Module مع النسخة والنظام والـpreconditions الفعلية.
مراجعة Module مطابق MSFCONSOLE
info [MATCHED_MODULE] show options
لا تشغّل exploit إذا لم يوجد تطابق واضح مع الإصدار والإعداد المكتشف.

6. Evidence / Handoff

ثبّت ما اكتشفته من PostgreSQL وحوّله للخطوة التالية بدل تكرار Post-Exploitation العام.

حفظ معلومات الإصدار والمستخدم KALI TERMINAL
PGPASSWORD='[PASSWORD]' psql -h [TARGET] -p [PORT] -U [USERNAME] -d [DATABASE] -c 'SELECT version(), current_user, current_database();' > postgres_info.txt
حفظ قائمة قواعد البيانات KALI TERMINAL
PGPASSWORD='[PASSWORD]' psql -h [TARGET] -p [PORT] -U [USERNAME] -d [DATABASE] -c '\l' > postgres_databases.txt
حفظ قائمة Roles KALI TERMINAL
PGPASSWORD='[PASSWORD]' psql -h [TARGET] -p [PORT] -U [USERNAME] -d [DATABASE] -c '\du' > postgres_roles.txt
البحث محليًا في النتائج KALI TERMINAL
grep -Eai 'user|role|admin|host|password|secret|token|database' postgres_*.txt
تحقق من كل معلومة قبل اعتبارها Credential أو Target جديدًا.
فحص خدمة مرتبطة اكتشفتها KALI TERMINAL
nmap -Pn -sV -p[DISCOVERED_PORT] [DISCOVERED_HOST]
إذا PostgreSQL كشف Host/Credential لخدمة أخرى، انتقل إلى Cheatsheet تلك الخدمة.
