1. Detect CMS

ابدأ بإثبات أن الموقع WordPress أو CMS محدد.

Fingerprint KALI TERMINAL
whatweb [URL]
GENERAL REFERENCE: ابحث عن WordPress أو تقنيات CMS ظاهرة.
Common WordPress paths KALI TERMINAL
curl -I [WP_BASE]/wp-login.php curl -I [WP_BASE]/wp-admin/ curl -I [WP_BASE]/wp-content/
GENERAL REFERENCE — [WP_BASE] = مسار تثبيت WordPress؛ قد يكون / أو subdirectory. وجود المسار وحده قرينة، وليس إثبات نسخة.

2. WordPress Enumeration

استخدم WPScan فقط على الموقع المصرح وبعد إثبات WordPress.

Basic scan KALI TERMINAL
wpscan --url [URL]
GENERAL REFERENCE.
GENERAL REFERENCE — Version enumeration: ابحث عن WordPress version إن أمكن تحديده.
Users / plugins / themes KALI TERMINAL
wpscan --url [URL] --enumerate u,p,t
GENERAL REFERENCE: اربط أي finding بالإصدار الفعلي قبل الاستغلال.
GENERAL REFERENCE — User enumeration: usernames discovered. Plugin/theme enumeration: names + versions عندما تكون ظاهرة.

3. Login

بعد الحصول على بيانات دخول صالحة، جرّب تسجيل الدخول إلى wp-admin.

Admin portal BROWSER
[WP_BASE]/wp-admin/
استخدم مسار wp-admin مع [WP_BASE] كـplaceholder لمسار تثبيت WordPress.
Credentials BROWSER
[USERNAME] / [PASSWORD]
اختبر فقط بيانات مصرح بها أو خرجت من workflow داخل اللاب.
WPScan credential testing KALI TERMINAL
wpscan --url [TARGET_URL] -U [USERLIST] -P [WORDLIST]
اختبر فقط قوائم بيانات اعتماد مصرح بها داخل اللاب.
GENERAL REFERENCE — النجاح = بيانات دخول صالحة يمكن التحقق منها عبر login.

4. Version-backed Findings

لا تحوّل الملف إلى exploit list.

Plugin/theme check KALI / BROWSER
[PLUGIN_OR_THEME] [VERSION]
لا تستخدم exploit إلا عند تطابق المكوّن والإصدار والشروط المسبقة.
Search local exploit reference KALI TERMINAL
searchsploit wordpress [COMPONENT] [VERSION]
GENERAL REFERENCE: راجع تفاصيل exploit قبل التنفيذ.

5. WordPress Database → Login Path

قد يظهر مسار WordPress بعد الوصول إلى MySQL وجدول المستخدمين الخاص بالتثبيت.

Database selection MYSQL SESSION
use [WP_DATABASE]; show tables; select * from [WP_PREFIX]_users;
استبدل [WP_DATABASE] و[WP_PREFIX] بالقيم الفعلية داخل اللاب، ولا تحفظ hashes/passwords فعلية داخل الملف.
Handoff to CMS login BROWSER
[WP_BASE]/wp-admin/
بعد الحصول على Credentials صالحة، انتقل للـlogin بدل تكرار مسار قاعدة البيانات هنا.
