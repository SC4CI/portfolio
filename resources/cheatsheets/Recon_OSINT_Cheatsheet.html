1. Scope First

حدد النطاق قبل جمع أي معلومات.

سجل النطاق المصرح KALI TERMINAL
[TARGET_DOMAIN] [TARGET_IP_OR_RANGE]
لا توسع البحث إلى أصول خارج النطاق حتى لو ظهرت مرتبطة بالهدف.
GENERAL REFERENCE — Passive Recon = جمع معلومات دون تفاعل مباشر مع أنظمة الهدف. Active Recon = تفاعل مباشر مع الهدف مثل probing/scanning.

2. WHOIS & DNS

Passive/low-impact معلومات التسجيل وDNS.

WHOIS KALI TERMINAL
whois [TARGET_DOMAIN]
DNS records KALI TERMINAL
dig [TARGET_DOMAIN] A dig [TARGET_DOMAIN] MX dig [TARGET_DOMAIN] NS

3. Subdomains

اجمع subdomains ثم تحقق منها قبل اعتبارها targets.

Certificate transparency clue BROWSER
crt.sh → search [TARGET_DOMAIN]
استخدم النتائج كمرشحين، ثم تحقق DNS/HTTP منها.
Alternative — Sublist3r KALI TERMINAL
sublist3r -d [TARGET_DOMAIN]
طريقة بديلة ضمن Subdomain Enumeration.
Alternative — Subfinder KALI TERMINAL
subfinder -d [TARGET_DOMAIN]
طريقة بديلة ضمن Subdomain Enumeration.

4. Search Engines

GENERAL REFERENCE — استعلامات بسيطة للعثور على صفحات عامة داخل النطاق.

Google dorks أساسية BROWSER
site:[TARGET_DOMAIN] site:[TARGET_DOMAIN] filetype:pdf site:[TARGET_DOMAIN] inurl:login
النتائج العامة لا تعني السماح باختبار أصل خارج النطاق.

5. Public Information

ابحث عن emails/technologies فقط بما يخدم النطاق.

Email/domain clues BROWSER
"@[TARGET_DOMAIN]" "[TARGET_DOMAIN]" technology

6. Handoff to Active Recon

حوّل النتائج المؤكدة فقط إلى targets للفحص النشط.

Workflow KALI TERMINAL
Scope → Passive Recon → Validate DNS → Build Target List → Active Scan
تفاصيل Nmap لا تتكرر هنا؛ استخدم قسم Port Scanning داخل ملف الخدمة التي اكتشفتها في هذه المكتبة.
GENERAL REFERENCE — Passive findings → Target list → Active scanning → Service cheatsheet
