PORT 11211 / TCP — MEMCACHED

Memcached — من الفحص إلى تقييم الـCache المكشوف

Quick Service Reference — مرجع عملي للـLab: اكتشاف الخدمة، Enumeration آمن، تقييم الوصول غير الموثق، ثم الخطوة التالية.

✒ Abdullah Nasser Almsan — Personal Pentest Reference
ملاحظة عن البورت: Memcached يستخدم غالبًا 11211/TCP، وقد يُنقل لبورت آخر أو يُحصر على localhost/private network. إذا لم يظهر على البورت الافتراضي، نفّذ Full TCP Scan قبل استبعاده.

1. Reconnaissance

ثبت الهدف ومسار الشبكة قبل لمس خدمة الـcache.

معرفة عنوانك والواجهة KALI TERMINAL
ip a ip route
حدد واجهة الـVPN/اللاب ومسار الشبكة قبل الفحص.
اختبار الوصول للهدف KALI TERMINAL
ping -c 4 [TARGET]
إذا ICMP محجوب، استخدم -Pn في Nmap ولا تعتبر الهدف Down.
اكتشاف الأجهزة عند الحاجة KALI TERMINAL
nmap -sn [SUBNET] netdiscover -r [SUBNET]

2. Port Scanning

أكد 11211/TCP والإصدار، ثم ابحث عن بورت غير قياسي عند الحاجة.

فحص Memcached الافتراضي KALI TERMINAL
nmap -Pn -p11211 -sV [TARGET]
11211/TCP هو المنفذ الشائع لخدمة Memcached.
Default Scripts + Version KALI TERMINAL
nmap -Pn -p11211 -sC -sV [TARGET]
فحص TCP شامل إذا لم تظهر الخدمة KALI TERMINAL
nmap -Pn -p- --min-rate 1000 [TARGET]
استخدم معدل الفحص المناسب فقط داخل Lab أو وفق قواعد الاختبار المصرح.
إعادة فحص البورت المكتشف KALI TERMINAL
nmap -Pn -p[PORT] -sC -sV [TARGET]
إذا ظهرت Memcached على بورت غير قياسي، استخدم [PORT] الفعلي في بقية الخطوات.

3. Enumeration

استخدم أوامر قراءة فقط لفهم الخدمة والإحصاءات بدون تغيير الـcache.

Service / Stats Enumeration

Nmap Memcached Info KALI TERMINAL
nmap -Pn -p[PORT] --script memcached-info [TARGET]
إذا سمحت الخدمة بالاستعلام قد يعرض معلومات runtime وإحصاءات مفيدة.
اختبار بروتوكول Text يدويًا KALI TERMINAL
printf 'version\r\nquit\r\n' | nc [TARGET] [PORT]
VERSION [VERSION]
رجوع VERSION يؤكد أن الخدمة تستجيب لأمر Memcached النصي.
عرض الإحصاءات العامة KALI TERMINAL
printf 'stats\r\nquit\r\n' | nc [TARGET] [PORT]
راجع version وuptime وcurr_items وbytes وlimit_maxbytes بدون تعديل البيانات.
عرض Slabs KALI TERMINAL
printf 'stats slabs\r\nquit\r\n' | nc [TARGET] [PORT]
يفيد في معرفة slab classes المستخدمة قبل أي enumeration إضافي.
عرض Items metadata KALI TERMINAL
printf 'stats items\r\nquit\r\n' | nc [TARGET] [PORT]
قد يعرض معلومات عن العناصر المخزنة حسب slab؛ لا تفترض وجود keys معينة.
Memcached ليس قاعدة بيانات دائمة؛ البيانات الموجودة في الذاكرة تعتمد على التطبيق والوقت. لا تخترع أسماء Keys أو محتوى غير ظاهر فعليًا.

4. Credential Testing

حدد أولًا هل توجد Authentication فعلية؛ Memcached لا يُعامل مثل SSH/FTP.

Access Model

اختبار الوصول بدون Authentication KALI TERMINAL
printf 'stats\r\nquit\r\n' | nc [TARGET] [PORT]
إذا رجعت STATS مباشرة فواجهة النص تسمح بالاستعلام من موقعك الشبكي.
التحقق من دعم SASL/Authentication عبر الخدمة KALI TERMINAL
nmap -Pn -sV -p[PORT] [TARGET]
Memcached قد يُبنى مع SASL، لكن Text protocol التقليدي لا يقدم Login prompt مثل SSH/FTP. لا تطبق brute force عشوائيًا بدون إثبات آلية مصادقة مناسبة.
البحث عن Modules متاحة بدل اختراع اسم MSFCONSOLE
search memcached search type:auxiliary memcache
إذا ظهر Scanner مناسب في إصدار Metasploit عندك، راجع info [MODULE] وshow options قبل الاستخدام.
تنبيه: لا تستخدم Hydra أو Password Spraying تلقائيًا على 11211. أولًا أثبت أن الخدمة تستخدم آلية Authentication قابلة للاختبار وأن ذلك ضمن نطاق اللاب.

5. Cache Access / Exposure Assessment

ركز على Misconfiguration والوصول المكشوف، ولا تشغل CVE أو أوامر تغيير عشوائية.

Misconfiguration / Exposed Cache

تقييم التعرض من خلال الإحصاءات KALI TERMINAL
printf 'stats\r\nquit\r\n' | nc [TARGET] [PORT]
الوصول بدون مصادقة من شبكة غير موثوقة يعتبر Misconfiguration مهمة؛ اربطها بموقع الخدمة وصلاحيات الشبكة.
اختبار قراءة Key معروف فقط KALI TERMINAL
printf 'get [KNOWN_KEY]\r\nquit\r\n' | nc [TARGET] [PORT]
استخدم Key ظهر لك فعليًا من التطبيق/اللاب أو أعطي لك صراحة. لا تخمّن أسرارًا أو بيانات مستخدمين.
فحص Modules/Exploits المناسبة للإصدار MSFCONSOLE
search memcached info [MODULE] show options
لا تشغّل Exploit أو Module تغييري قبل التأكد من الخدمة والإصدار والـpreconditions. لا توجد هنا نتيجة Memcached exploit محددة أو نتيجة Lab ناجحة ثابتة.
لا تستخدم أوامر مثل flush_all أو delete أو set على بيانات حقيقية؛ هذه تغيّر/تمسح الـcache وقد تعطل التطبيق.

6. Findings / Handoff

وثّق ما أثبتته واربط الـcache بالتطبيق بدون حذف أو تعديل البيانات.

حفظ الإحصاءات محليًا KALI TERMINAL
printf 'stats\r\nquit\r\n' | nc [TARGET] [PORT] > memcached_stats.txt
يحفظ Evidence محليًا بدون تعديل الخدمة.
تأكيد النسخة مرة أخيرة KALI TERMINAL
printf 'version\r\nquit\r\n' | nc [TARGET] [PORT]
سجّل النسخة الفعلية فقط إذا أعادها الخادم.
ربط Memcached بالتطبيق KALI TERMINAL
nmap -Pn -sV [TARGET]
بعد إثبات Memcached، راجع الخدمات الأخرى على نفس الهدف وابحث عن التطبيق الذي يستخدم الـcache؛ غالبًا القيمة العملية تأتي من ربط الخدمة بسياق التطبيق.
إذا حصلت على وصول للنظام من خدمة أخرى، راجع إعدادات Memcached محليًا ضمن Post-Exploitation العام بدل تكرار أوامر النظام داخل هذا الملف.
