1. Reconnaissance

ثبّت الهدف ومسار الشبكة قبل البحث عن IRC.

معرفة عنوانك ومسار الشبكة KALI TERMINAL
ip a ip route
اختبار الوصول للهدف KALI TERMINAL
ping -c 4 [TARGET]
عدم الرد على ICMP لا يعني أن الهدف Down؛ استخدم -Pn عند الحاجة.
اكتشاف الأجهزة داخل Subnet KALI TERMINAL
nmap -sn [SUBNET]

2. Port Scanning

IRC يرتبط غالبًا بـ6667/TCP، وقد يظهر أيضًا على بورتات أخرى مثل 6697 عند استخدام TLS.

فحص IRC الافتراضي KALI TERMINAL
nmap -Pn -p6667 -sV [TARGET]
فحص بورتات IRC الشائعة KALI TERMINAL
nmap -Pn -p6660-6669,6697 -sV [TARGET]
Default Scripts + Version KALI TERMINAL
nmap -Pn -p[PORT] -sC -sV [TARGET]
فحص TCP شامل KALI TERMINAL
nmap -Pn -p- --min-rate 1000 [TARGET]
استخدم معدل الفحص المناسب للـLab أو قواعد الاختبار المصرح.

3. Enumeration

استخرج Banner واسم IRC daemon والإصدار والقدرات والقنوات المتاحة قبل أي اختبار إضافي.

IRC Info عبر Nmap KALI TERMINAL
nmap -Pn -p[PORT] --script irc-info [TARGET]
راجع Server name وVersion وأي معلومات يعيدها الخادم.
Banner يدوي عبر Netcat KALI TERMINAL
nc -nv [TARGET] [PORT]
بعد الاتصال يمكنك إرسال NICK وUSER لتسجيل جلسة IRC بسيطة.
تسجيل Client يدوي NETCAT / IRC SESSION
NICK [NICKNAME] USER [USERNAME] 0 * :[REALNAME]
إذا قَبِل الخادم التسجيل ستظهر رسائل ترحيب رقمية IRC؛ الأرقام والمحتوى تختلف حسب الخادم.
طلب معلومات الخادم NETCAT / IRC SESSION
VERSION
عرض معلومات الخادم العامة NETCAT / IRC SESSION
INFO
عرض القنوات المعلنة NETCAT / IRC SESSION
LIST
بعض الخوادم قد تمنع LIST أو تحده حسب الإعدادات.
عرض المستخدمين في قناة NETCAT / IRC SESSION
JOIN #[CHANNEL] NAMES #[CHANNEL]
عرض معلومات مستخدم NETCAT / IRC SESSION
WHOIS [NICKNAME]
اختبار IRC TLS إذا اكتشفته KALI TERMINAL
openssl s_client -connect [TARGET]:[PORT] -servername [TARGET]
استخدمه عندما يبيّن الفحص أن البورت يستخدم TLS، وليس لمجرد افتراض أن 6697 موجود.

4. Credential Testing

IRC قد يستخدم Server Password أو NickServ/Services authentication حسب إعداد الشبكة؛ اختبر فقط ما اكتشفته فعليًا.

إرسال Server Password قبل التسجيل NETCAT / IRC SESSION
PASS [PASSWORD] NICK [NICKNAME] USER [USERNAME] 0 * :[REALNAME]
PASS هنا خاص بكلمة مرور اتصال الخادم إذا كان Listener يتطلبها.
NickServ Authentication عند وجوده IRC SESSION
PRIVMSG NickServ :IDENTIFY [USERNAME] [PASSWORD]
استخدم هذا فقط إذا أظهر الخادم وجود NickServ/Services؛ ليس كل IRC Server يستخدمه.
البحث عن IRC Login/Scanner Modules MSFCONSOLE
search type:auxiliary irc search irc
راجع Modules الموجودة في إصدار Metasploit لديك بدل افتراض اسم Scanner ثابت.
مراجعة Module مناسب قبل تشغيله MSFCONSOLE
info [IRC_MODULE] use [IRC_MODULE] show options
إذا كان الـModule يقوم Password Guessing، التزم بنطاق اللاب وحدود المحاولات.

5. Exploit Research / Version Matching

في IRC يعتمد الاستغلال بشدة على الـdaemon والإصدار والإعداد؛ لا تستخدم Exploit عشوائي لمجرد أن 6667 مفتوح.

تحذير: اربط أي Exploit باسم IRC daemon والإصدار والـpreconditions الفعلية. لا تعتبر Banner وحده إثباتًا للثغرة.
تثبيت معلومات الإصدار أولًا KALI TERMINAL
nmap -Pn -p[PORT] -sV --version-all [TARGET]
البحث في SearchSploit بعد معرفة المنتج والإصدار KALI TERMINAL
searchsploit [IRC_DAEMON] [VERSION]
اقرأ وصف الـExploit وتحقق من النسخة والنظام والمتطلبات قبل الاستخدام.
فحص تفاصيل نتيجة SearchSploit KALI TERMINAL
searchsploit -x [EXPLOIT_PATH]
البحث عن Module مطابق في Metasploit MSFCONSOLE
search [IRC_DAEMON] search [IRC_DAEMON] [VERSION]
مراجعة الـModule والـTargets MSFCONSOLE
info [MATCHED_MODULE] use [MATCHED_MODULE] show options show targets
لا تنفذ exploit إذا لم تتطابق النسخة أو Target أو المتطلبات مع بيئة اللاب.
ضبط الهدف بعد التحقق من التطابق MSFCONSOLE
set RHOSTS [TARGET] set RPORT [PORT] show options
أكمل بقية الخيارات المطلوبة التي يعرضها الـModule نفسه فقط.

6. Evidence / Handoff

حوّل معلومات IRC إلى Targets أو Credentials أو مسارات لاحقة، وإذا حصلت Shell انتقل إلى ملف Post-Exploitation العام المناسب.

حفظ IRC Enumeration KALI TERMINAL
nmap -Pn -p[PORT] -sV --script irc-info [TARGET] -oN irc_enum.txt
فلترة المعلومات المهمة KALI TERMINAL
grep -Eai 'version|server|channel|user|host|admin|network' irc_enum.txt
فحص Host/Service جديد تم اكتشافه KALI TERMINAL
nmap -Pn -sV -p[DISCOVERED_PORT] [DISCOVERED_HOST]
إذا ظهرت خدمة جديدة، انتقل إلى Cheatsheet الخاص بها.
إذا حصلت Linux Shell: إثبات السياق فقط VICTIM SHELL
whoami id hostname
بعد إثبات الوصول انتقل إلى Linux Post-Exploitation Cheatsheet بدل تكرار الخطوات العامة هنا.
إذا حصلت Windows Shell: إثبات السياق فقط VICTIM SHELL
whoami hostname
بعد إثبات الوصول انتقل إلى Windows Post-Exploitation Cheatsheet.
