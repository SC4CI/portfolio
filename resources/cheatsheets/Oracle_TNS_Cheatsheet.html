Oracle TNS — من الفحص إلى ما بعد الاستغلال

Quick Service Reference — مرجع عملي للـLab: اكتشاف Listener، تحديد SID/Service، Credential Testing، Enumeration داخل Oracle ثم الانتقال للخطوة التالية.

1. Reconnaissance

ثبّت عنوانك والهدف ومسار الشبكة قبل فحص Oracle TNS Listener.

معرفة عنوانك ومسار الشبكة KALI TERMINAL
ip a ip route
اختبار الوصول للهدف KALI TERMINAL
ping -c 4 [TARGET]
إذا ICMP محجوب، استخدم -Pn في Nmap ولا تستبعد الهدف.
اكتشاف الأجهزة داخل الشبكة عند الحاجة KALI TERMINAL
nmap -sn [SUBNET]

2. Port Scanning

Oracle TNS Listener يستخدم غالبًا 1521/TCP، لكنه قد يعمل على بورت آخر.

فحص البورت الافتراضي KALI TERMINAL
nmap -Pn -p1521 -sV [TARGET]
GENERAL REFERENCE — النجاح = Nmap يعرّف Oracle TNS/Listener أو يؤكد الخدمة المتوقعة على البورت.
Default Scripts + Version KALI TERMINAL
nmap -Pn -p1521 -sC -sV [TARGET]
فحص TCP شامل KALI TERMINAL
nmap -Pn -p- --min-rate 1000 [TARGET]
استخدم معدل الفحص المناسب للـLab أو قواعد الاختبار المصرح.
إعادة فحص البورت المكتشف KALI TERMINAL
nmap -Pn -p[PORT] -sC -sV [TARGET]

3. Enumeration

الهدف الأساسي هو تحديد Listener ثم اكتشاف SID أو Service Name قبل محاولة الاتصال بقاعدة البيانات.

Oracle TNS Version عبر Nmap KALI TERMINAL
nmap -Pn -p[PORT] --script oracle-tns-version [TARGET]
استخدم نتيجة الإصدار لتوجيه الخطوات التالية بدل تخمين نسخة Oracle.
GENERAL REFERENCE — النجاح = استخراج معلومات Listener/Version عندما يسمح الخادم بذلك.
Enumeration عبر tnscmd10g KALI TERMINAL
tnscmd10g version -h [TARGET] -p [PORT]
إذا كانت الأداة موجودة في بيئتك، تساعد في استعلام Listener.
اختبار Listener عبر tnsping KALI TERMINAL
tnsping [TARGET]:[PORT]
يتطلب Oracle client tools وقد تختلف صيغة الاتصال حسب إعداد العميل.
SID Enumeration عبر Nmap KALI TERMINAL
nmap -Pn -p[PORT] --script oracle-sid-brute [TARGET]
SID enumeration يرسل عدة محاولات إلى Listener؛ استخدمه ضمن النطاق المصرح فقط.
GENERAL REFERENCE — النجاح = ظهور SID/Service identifiers قابلة للاستخدام في خطوة الاتصال التالية.
SID Enumeration عبر ODAT KALI TERMINAL
odat sidguesser -s [TARGET] -p [PORT]
ODAT أداة مخصصة لاختبار Oracle وتفيد في اكتشاف SID داخل بيئات اللاب.
عرض خيارات ODAT المتاحة KALI TERMINAL
odat --help
راجع أسماء الـmodules والخيارات في إصدار ODAT المثبت لديك قبل تشغيل أي وحدة.
البحث عن Oracle scanners في Metasploit MSFCONSOLE
search type:auxiliary oracle search oracle tns
مراجعة Scanner مناسب MSFCONSOLE
info [ORACLE_SCANNER_MODULE] use [ORACLE_SCANNER_MODULE] show options

4. Credential Testing

بعد معرفة SID/Service Name، اختبر Credential معروف أولًا ثم Password Testing مصرحًا به فقط.

اتصال SQL*Plus باستخدام SID/Service KALI TERMINAL
sqlplus '[USERNAME]/[PASSWORD]@[TARGET]:[PORT]/[SERVICE_NAME]'
نجاح الاتصال يعتمد على Connection Identifier الصحيح وعلى إعداد Listener والخدمة.
GENERAL REFERENCE — النجاح = قبول credentials وConnection Identifier وفتح SQL session.
اختبار حساب عبر ODAT KALI TERMINAL
odat passwordguesser -s [TARGET] -p [PORT] -d [SID] --accounts-file [USERPASS_FILE]
Password guessing قد يسبب Lockout أو ضوضاء؛ نفذه فقط داخل Lab أو بتصريح صريح.
البحث عن Oracle Login Scanner في Metasploit MSFCONSOLE
search oracle_login search type:auxiliary oracle
تشغيل Login Scanner المتاح MSFCONSOLE
use [ORACLE_LOGIN_MODULE] show options set RHOSTS [TARGET] set RPORT [PORT] set SID [SID] run
راجع show options؛ الخيارات الفعلية تعتمد على الـModule وإصدار Metasploit.

5. Database Access / Permission Assessment

بعد دخول ناجح، قيّم صلاحيات الحساب ومعلومات قاعدة البيانات قبل التفكير في أي استغلال إضافي.

تحذير: تأكد من Oracle Version والـSID/Service والصلاحيات والـpreconditions قبل أي exploit. لا تشغّل CVE أو Module عشوائيًا لمجرد أن 1521 مفتوح.
تأكيد المستخدم الحالي SQLPLUS SESSION
SELECT USER FROM dual;
تحديد إصدار قاعدة البيانات SQLPLUS SESSION
SELECT banner FROM v$version;
قد تتطلب بعض الـviews صلاحيات مناسبة.
عرض صلاحيات Session الحالية SQLPLUS SESSION
SELECT * FROM session_privs;
عرض Roles الممنوحة SQLPLUS SESSION
SELECT * FROM session_roles;
عرض الجداول التي يمكن للحساب رؤيتها SQLPLUS SESSION
SELECT owner, table_name FROM all_tables WHERE ROWNUM <= 50;
استخدم Enumeration أولًا ثم اقرأ فقط البيانات الموجودة ضمن نطاق اللاب.
قراءة جدول مصرح بعد اكتشافه SQLPLUS SESSION
SELECT * FROM [OWNER].[TABLE] WHERE ROWNUM <= 20;
GENERAL REFERENCE — النجاح = رجوع Rows يملك الحساب الحالي صلاحية قراءتها.
البحث عن Modules مرتبطة بالإصدار MSFCONSOLE
search oracle search [ORACLE_VERSION]
طابق أي Module مع الإصدار والنظام والـpreconditions الفعلية.
مراجعة Module مطابق قبل التنفيذ MSFCONSOLE
info [MATCHED_MODULE] show options
إذا لم يوجد تطابق واضح، لا تشغّل exploit.

6. Evidence / Handoff

ثبّت ما اكتشفته من Oracle وحوّل المعلومات للخدمة أو المرحلة التالية بدون تكرار Post-Exploitation العام.

حفظ معلومات Listener والإصدار KALI TERMINAL
nmap -Pn -p[PORT] --script oracle-tns-version [TARGET] -oN oracle_tns.txt
حفظ معلومات المستخدم والإصدار بعد الدخول SQLPLUS SESSION
SPOOL oracle_session.txt SELECT USER FROM dual; SELECT banner FROM v$version; SPOOL OFF
حفظ Roles والصلاحيات SQLPLUS SESSION
SPOOL oracle_privs.txt SELECT * FROM session_privs; SELECT * FROM session_roles; SPOOL OFF
البحث محليًا في النتائج KALI TERMINAL
grep -Eai 'user|role|priv|host|service|sid|version|password|secret' oracle_*.txt
تحقق من كل قيمة قبل اعتبارها Credential أو Target جديدًا.
فحص Host/Service جديد تم اكتشافه KALI TERMINAL
nmap -Pn -sV -p[DISCOVERED_PORT] [DISCOVERED_HOST]
إذا قادت المعلومات إلى خدمة أخرى، انتقل إلى Cheatsheet الخدمة المناسبة.
