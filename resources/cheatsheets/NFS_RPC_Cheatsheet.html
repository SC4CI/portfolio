1. Reconnaissance

حدد الهدف والشبكة أولًا قبل فحص RPC/NFS.

معرفة عنوانك ومسار الشبكة KALI TERMINAL
ip a ip route
راقب واجهة الـVPN أو الشبكة التي تصل منها إلى الهدف.
اختبار الوصول المبدئي KALI TERMINAL
ping -c 4 [TARGET]
عدم الرد لا يعني أن الهدف غير متاح؛ انتقل إلى Nmap مع -Pn عند الحاجة.
RPCbind يرتبط غالبًا بـ111 TCP/UDP، وNFS غالبًا بـ2049 TCP/UDP. قد تظهر خدمات RPC إضافية على منافذ ديناميكية.

2. Port Scanning

ابدأ بـ111 و2049، ثم اكتشف أي منافذ RPC إضافية.

فحص TCP للخدمات الأساسية KALI TERMINAL
nmap -Pn -sV -p111,2049 [TARGET]
✓ ظهور rpcbind على 111 أو nfs على 2049 يستحق Enumeration مباشر.
فحص UDP للخدمات الأساسية KALI TERMINAL
sudo nmap -Pn -sU -sV -p111,2049 [TARGET]
فحص RPC عبر Nmap KALI TERMINAL
nmap -Pn -sV --script=rpcinfo -p111 [TARGET]
يساعد في كشف RPC programs والمنافذ المرتبطة بها.
فحص TCP شامل عند الحاجة KALI TERMINAL
nmap -p- --min-rate=1000 -T4 [TARGET]
RPC قد يربط بعض الخدمات بمنافذ غير ثابتة؛ لا تكتفِ بـ111 و2049 إذا ظهرت مؤشرات إضافية.

3. Enumeration

اكتشف RPC programs وNFS exports ثم افحص الملفات والصلاحيات قبل أي محاولة استغلال.

RPC Enumeration يدوي KALI TERMINAL
rpcinfo -p [TARGET]
اعرض البرامج المسجلة مع rpcbind والبروتوكولات والمنافذ.
عرض NFS Exports KALI TERMINAL
showmount -e [TARGET]
ابحث عن المسارات المصدّرة ومن يسمح له بالوصول إليها.
NFS Enumeration عبر Nmap KALI TERMINAL
nmap -p111,2049 --script=nfs-showmount,nfs-ls,nfs-statfs [TARGET]
يوفر مسارًا بديلًا لرؤية exports والملفات ومعلومات filesystem عندما يسمح الخادم.
إنشاء Mount Point محلي KALI TERMINAL
sudo mkdir -p /mnt/nfs
Mount للـExport KALI TERMINAL
sudo mount -t nfs [TARGET]:[EXPORT] /mnt/nfs
إذا فشل، راجع export restrictions ونسخة NFS وخيارات mount بدل افتراض أن الـexport غير قابل للوصول.
فحص الملفات والـUID/GID KALI TERMINAL
ls -lan /mnt/nfs find /mnt/nfs -maxdepth 2 -type f -ls
الخيار -n يعرض UID/GID رقميًا، وهذا مهم لأن NFS يعتمد كثيرًا على هوية المستخدم الرقمية.

4. Access / Permission Testing

NFS التقليدي لا يستخدم Username/Password مثل SSH؛ الاختبار هنا يركز على قيود الـExport وهوية UID/GID.

التحقق من الوصول المسموح للـExport KALI TERMINAL
showmount -e [TARGET]
راجع هل الـexport متاح لشبكتك/جهازك أو مقيد بعنوان أو subnet محدد.
اختبار القراءة بعد Mount KALI TERMINAL
ls -la /mnt/nfs cat /mnt/nfs/[READABLE_FILE]
نفّذ فقط على ملف مصرح بقراءته داخل اللاب.
اختبار الكتابة بشكل آمن KALI TERMINAL
touch /mnt/nfs/nfs_write_test ls -l /mnt/nfs/nfs_write_test rm /mnt/nfs/nfs_write_test
استخدم ملف اختبار جديد بدل تعديل ملفات موجودة.
✓ نجاح إنشاء الملف وحذفه يؤكد Write Access على المسار الحالي.
إذا رفضت الصلاحيات رغم نجاح الـmount، افحص UID/GID وroot_squash بدل محاولة Password Brute Force غير المناسبة لـNFS.

5. NFS Misconfiguration Abuse

المسار المهم في NFS هو سوء إعداد الـExports والصلاحيات، خصوصًا UID/GID وroot_squash/no_root_squash.

فحص خصائص الملفات المهمة KALI TERMINAL
find /mnt/nfs -xdev -type f -perm -4000 -ls find /mnt/nfs -xdev -writable -ls
ابحث عن ملفات SUID أو ملفات قابلة للكتابة لها أثر فعلي، بدون تعديلها مباشرة.
التحقق من UID/GID Ownership KALI TERMINAL
ls -lan /mnt/nfs/[PATH]
إذا تطابق UID/GID محلي مع مالك الملفات فقد تحصل على صلاحيات مرتبطة بذلك المستخدم على الـexport.
التحقق من سلوك Root Squashing KALI TERMINAL
sudo touch /mnt/nfs/root_test ls -ln /mnt/nfs/root_test sudo rm -f /mnt/nfs/root_test
إذا تحولت ملكية root إلى nobody/nogroup فهذا مؤشر على root_squash؛ لا تفترض no_root_squash بدون تحقق.
تحذير: لا تعدّل ملفات تنفيذية أو SUID ولا تنشئ backdoor لمجرد وجود Write Access. أي مسار Privilege Escalation يعتمد على سوء إعداد فعلي وبيئة Lab مصرح بها، ويُستكمل في ملف Privilege Escalation المخصص.

6. Post-Access Verification

بعد إثبات الوصول إلى الـExport، اجمع المعلومات اللازمة للخطوة التالية ثم افصل الـmount بشكل نظيف.

حصر الملفات القابلة للقراءة/الكتابة KALI TERMINAL
find /mnt/nfs -xdev -type f -readable -ls find /mnt/nfs -xdev -type f -writable -ls
تعامل مع النتائج كـleads لخدمات أو مستخدمين آخرين، ولا تكرر Credential Access الكامل هنا.
البحث عن مؤشرات إعدادات وخدمات KALI TERMINAL
find /mnt/nfs -maxdepth 3 -type f \( -name '*.conf' -o -name '*.ini' -o -name '*.service' \) -ls
افحص فقط الملفات المرتبطة بهدف اللاب ولا تنسخ محتوى حساس بلا حاجة.
فصل الـNFS Mount بعد الانتهاء KALI TERMINAL
cd / sudo umount /mnt/nfs
✓ انتهاء الأمر بدون خطأ يعني أن الـmount تم فصله.
إذا كشفت الملفات Credentials أو مفاتيح أو مسار Privilege Escalation، انتقل للـCheatsheet المتخصص المناسب بدل توسيع ملف NFS/RPC.
