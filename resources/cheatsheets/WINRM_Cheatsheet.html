WinRM — من الفحص إلى Remote PowerShell

1. Reconnaissance

حدد الهدف ومسار الشبكة قبل فحص Windows Remote Management.

معرفة عنوانك ومسار الشبكة KALI TERMINAL
ip a ip route
راقب واجهة الـVPN أو الشبكة التي تصل منها إلى الهدف.
اختبار الوصول المبدئي KALI TERMINAL
ping -c 4 [TARGET]
إذا لم يرد ICMP لا تستبعد الجهاز؛ استخدم Nmap مع -Pn.
WinRM يستخدم عادة HTTP على 5985/TCP وHTTPS على 5986/TCP، وقد تتم تهيئته بشكل مختلف؛ اكتشف الخدمة قبل افتراض البورت.

2. Port Scanning

ابحث عن منافذ WinRM القياسية ثم وسّع الفحص إذا لم تظهر.

فحص منافذ WinRM القياسية KALI TERMINAL
nmap -Pn -sV -p5985,5986 [TARGET]
✓ ظهور 5985 أو 5986 مفتوحًا مع HTTP/HTTPS أو Microsoft HTTPAPI مؤشر قوي يستحق Enumeration إضافي.
فحص كل TCP إذا لم تظهر المنافذ القياسية KALI TERMINAL
nmap -p- --min-rate=1000 -T4 [TARGET]
فحص مركز للبورت المكتشف KALI TERMINAL
nmap -Pn -sC -sV -p[PORT] [TARGET]
5985 عادة WinRM عبر HTTP و5986 عبر HTTPS. وجود HTTP لا يعني أن بيانات الاعتماد تُرسل كنص صريح؛ طريقة المصادقة تحدد الحماية الفعلية.

3. Enumeration

أكد WinRM وافهم الـendpoint وطرق المصادقة قبل محاولة الدخول.

فحص HTTP headers/title على WinRM KALI TERMINAL
nmap -p[PORT] --script=http-headers,http-title [TARGET]
ابحث عن مؤشرات Microsoft HTTPAPI أو WS-Management.
طلب WS-Man endpoint يدويًا KALI TERMINAL
curl -i http://[TARGET]:5985/wsman
الرد 401 مع WWW-Authenticate قد يؤكد وجود endpoint ويبين آليات المصادقة المدعومة.
فحص الخدمة عبر Metasploit MSFCONSOLE
search winrm use auxiliary/scanner/winrm/winrm_auth_methods set RHOSTS [TARGET] set RPORT [PORT] run
تحقق من اسم الموديول المتاح في نسخة Metasploit لديك قبل التشغيل.
WinRM مبني على WS-Management ويُستخدم للإدارة عن بعد؛ الوصول الناجح غالبًا يعطي PowerShell/command execution حسب صلاحيات الحساب.

4. Credential Testing

اختبر بيانات الاعتماد المصرح بها ثم تحقق من نجاحها بأداة WinRM فعلية.

اختبار Login عبر Metasploit MSFCONSOLE
use auxiliary/scanner/winrm/winrm_login set RHOSTS [TARGET] set RPORT [PORT] set USER_FILE [USERLIST] set PASS_FILE [WORDLIST] run
استخدم قوائم اللاب فقط وراجع سياسة Account Lockout قبل أي Password Testing.
التحقق عبر Evil-WinRM KALI TERMINAL
evil-winrm -i [TARGET] -u [USERNAME] -p '[PASSWORD]'
لـHTTPS أو إعدادات مختلفة راجع خيارات evil-winrm المناسبة للـendpoint.
✓ نجاح المصادقة يفتح prompt تفاعلي لـEvil-WinRM/PowerShell.
Credential Reuse لحساب معروف KALI TERMINAL
evil-winrm -i [TARGET] -u [USERNAME] -p '[PASSWORD]'
إذا حصلت على credentials بشكل مشروع من خدمة أخرى في نفس اللاب، اختبر إعادة استخدامها بدل اختراع بيانات جديدة.
تنبيه: Password spraying/brute force قد يقفل الحسابات. التزم بالـscope وسياسة اللاب ولا تستخدم معدلات عشوائية.

5. Authenticated Remote Access

في WinRM يكون المسار العملي غالبًا استغلال ضعف المصادقة/إعادة استخدام credentials للوصول البعيد، لا تشغيل CVE عشوائي.

فتح Remote PowerShell عبر Evil-WinRM KALI TERMINAL
evil-winrm -i [TARGET] -u [USERNAME] -p '[PASSWORD]'
✓ ظهور Evil-WinRM shell يعني أن الوصول البعيد نجح.
تنفيذ أمر عبر Metasploit WinRM MSFCONSOLE
use auxiliary/scanner/winrm/winrm_cmd set RHOSTS [TARGET] set RPORT [PORT] set USERNAME [USERNAME] set PASSWORD [PASSWORD] set CMD whoami run
مسار بديل للتحقق من command execution باستخدام بيانات اعتماد صالحة.
فتح جلسة PowerShell من Windows عند توفر Credentials POWERSHELL
$cred = Get-Credential Enter-PSSession -ComputerName [TARGET] -Credential $cred
يحتاج أن تكون بيئة WinRM/TrustedHosts أو الدومين مهيأة بما يسمح بالاتصال.
قاعدة الاستغلال: لا تضف CVE فقط لأن WinRM مفتوح. اربط أي exploit بإصدار وOS وpreconditions موثقة أولًا.

6. Post-Exploitation

بعد Remote Shell نفّذ التحقق الفوري فقط، واترك Privilege Escalation/Credential Access/Pivoting للملفات العامة.

تأكيد الهوية والمجموعات POWERSHELL
whoami whoami /groups
✓ يحدد الحساب والمجموعات التي تعمل بها الجلسة.
معلومات النظام POWERSHELL
hostname systeminfo
سجل إصدار Windows واسم الجهاز قبل أي مسار لاحق.
معلومات الشبكة POWERSHELL
ipconfig /all route print
تعطيك الواجهات والمسارات المتاحة من الجهاز الذي وصلت إليه.
فحص الامتيازات الحالية POWERSHELL
whoami /priv
استخدم النتيجة لتقرر هل تحتاج ملف Privilege Escalation المنفصل.
بعد التحقق من الوصول، لا تكرر هنا Post-Exploitation أو Credential Access أو Pivoting الكامل؛ استخدم Windows_Post_Exploitation_Cheatsheet.html وCredential_Access_Cheatsheet.html وPivoting_Cheatsheet.html الموجودة في المكتبة.
