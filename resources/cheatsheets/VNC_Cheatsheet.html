1. Reconnaissance

ثبّت مسار الشبكة والهدف قبل فحص خدمة VNC.

معرفة عنوانك ومسار الشبكة KALI TERMINAL
ip a ip route
التأكد من الوصول للهدف KALI TERMINAL
ping -c 4 [TARGET]
إذا ICMP محجوب، كمل بـNmap باستخدام -Pn.
اكتشاف الأجهزة عند الحاجة KALI TERMINAL
nmap -sn [SUBNET]

2. Port Scanning

VNC يستخدم غالبًا 5900، والشاشات الإضافية قد تظهر على 5901 و5902 وما بعدها.

فحص أشهر بورتات VNC KALI TERMINAL
nmap -Pn -p5900-5905 -sV [TARGET]
GENERAL REFERENCE — النجاح = Nmap يعرّف VNC/RFB أو يؤكد الخدمة المتوقعة على البورت.
Default scripts مع Version Detection KALI TERMINAL
nmap -Pn -p5900-5905 -sC -sV [TARGET]
فحص شامل للبورتات KALI TERMINAL
nmap -Pn -p- --min-rate 1000 [TARGET]
استخدم الفحص عالي المعدل داخل Lab أو حسب قواعد الاختبار المصرح.
فحص البورت المكتشف بدقة KALI TERMINAL
nmap -Pn -p[PORT] -sV -sC [TARGET]

3. Enumeration

حدد بروتوكول RFB، نوع المصادقة، واسم سطح المكتب قبل أي محاولة دخول.

Nmap VNC Info KALI TERMINAL
nmap -Pn -p[PORT] --script vnc-info [TARGET]
يساعد في إظهار معلومات RFB وSecurity Types التي يعلنها الخادم.
GENERAL REFERENCE — النجاح = ظهور RFB/Security Types أو معلومات خدمة تساعدك على اختيار مسار الوصول.
Nmap VNC Title KALI TERMINAL
nmap -Pn -p[PORT] --script vnc-title [TARGET]
قد يكشف اسم سطح المكتب أو معلومات مفيدة عن الجلسة.
قراءة Banner يدويًا KALI TERMINAL
nc -nv [TARGET] [PORT]
خوادم VNC/RFB عادة تبدأ بإعلان نسخة البروتوكول مثل RFB 003.xxx؛ لا تخترع نتيجة إذا لم تظهر فعليًا.
البحث عن VNC scanners في Metasploit MSFCONSOLE
search type:auxiliary vnc search vnc
راجع أسماء الـmodules الموجودة في إصدار Metasploit عندك بدل الاعتماد على اسم قديم.
مراجعة Scanner مناسب MSFCONSOLE
info [VNC_SCANNER_MODULE] use [VNC_SCANNER_MODULE] show options

4. Credential Testing

اختبر أولًا كلمة مرور معروفة، ثم Password Testing محدود داخل بيئة مصرح بها.

اتصال VNC عادي KALI TERMINAL
vncviewer [TARGET]:[DISPLAY]
عادة DISPLAY :0 يقابل 5900، و:1 يقابل 5901. بعض العملاء يقبلون [TARGET]::[PORT] للبورت الصريح.
اتصال على بورت صريح KALI TERMINAL
vncviewer [TARGET]::[PORT]
إذا طلب Password فهذا يؤكد وجود Authentication path يمكن اختباره.
Password Testing عبر Hydra KALI TERMINAL
hydra -P [WORDLIST] -s [PORT] [TARGET] vnc
VNC غالبًا يعتمد كلمة مرور للخدمة وليس Username تقليدي. تجنب brute force خارج Lab؛ قد يسبب ضوضاء أو حظرًا.
البحث عن VNC login modules MSFCONSOLE
search vnc_login search type:auxiliary vnc
اختر Login/Authentication scanner المتاح في نسختك ثم راجع show options قبل التشغيل.
تشغيل Scanner بعد ضبط الخيارات MSFCONSOLE
use [VNC_LOGIN_MODULE] show options set RHOSTS [TARGET] set RPORT [PORT] set PASS_FILE [WORDLIST] run
نفّذ Password Testing فقط ضمن النطاق المصرح به.

5. Remote Desktop Access

أهم مسار عملي في VNC هو ضعف/غياب المصادقة أو Credentials صحيحة؛ لا تضف CVEs عشوائية.

تحذير: تأكد من Version وSecurity Type والـPreconditions قبل أي exploit. لا تشغّل Module لمجرد أن 5900 مفتوح.
اختبار اتصال عند اكتشاف No Authentication KALI TERMINAL
vncviewer [TARGET]::[PORT]
إذا Enumeration أكد أن الخادم يسمح باتصال بدون Authentication، جرّب العميل مباشرة داخل اللاب.
GENERAL REFERENCE — النجاح = فتح Remote Desktop بدون طلب credentials عندما يكون No Authentication مؤكدًا.
الاتصال بعد اكتشاف Password صحيح KALI TERMINAL
vncviewer [TARGET]::[PORT]
أدخل كلمة المرور الصحيحة عند Prompt. نجاح الاتصال يعني وصولًا تفاعليًا لسطح المكتب بحسب صلاحيات جلسة VNC.
GENERAL REFERENCE — النجاح = فتح سطح المكتب البعيد ضمن صلاحيات جلسة VNC.
البحث عن Modules مرتبطة بالإصدار MSFCONSOLE
search vnc search [VNC_PRODUCT]
طابق أي نتيجة مع المنتج والإصدار الفعليين قبل استخدامها.
مراجعة تفاصيل أي Module قبل التنفيذ MSFCONSOLE
info [MATCHED_MODULE] show options
إذا لم يوجد تطابق واضح مع الإصدار/الإعداد المكتشف، لا تشغّل exploit.

6. Session Verification / Handoff

بعد الوصول لسطح المكتب، أكد هوية المستخدم والنظام فقط ثم انتقل لملف Post-Exploitation المناسب.

تأكيد المستخدم على Linux Desktop VNC REMOTE DESKTOP
whoami id
نفّذها داخل Terminal في سطح المكتب البعيد إذا كان النظام Linux.
تأكيد المستخدم على Windows Desktop VNC REMOTE DESKTOP
whoami hostname
نفّذها داخل CMD أو PowerShell في سطح المكتب البعيد إذا كان النظام Windows.
تأكيد معلومات النظام على Linux VNC REMOTE DESKTOP
uname -a hostname
تأكيد معلومات النظام على Windows VNC REMOTE DESKTOP
systeminfo
بعد إثبات الوصول والهوية والنظام، انتقل لملف Windows/Linux Post-Exploitation بدل حشر workflow كامل هنا.
